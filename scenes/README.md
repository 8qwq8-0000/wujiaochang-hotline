# Scenes

- `bootstrap`：启动、主入口及全局场景
- `ui`：主菜单、HUD、背包、结算界面
- `levels/rooms`：可抽取的预制战斗房间
- `actors/player`：玩家场景
- `actors/enemies`：敌人场景
- `levels/base/warehouse.tscn`：仓库与现有功能交互；当前没有 `actors/npcs/` 目录，人质救援不在开发范围
- `weapons`：手持武器表现、通用回退和新武器场景模板
- `combat`、`environment`、`items`、`presentation`：战斗节点、环境交互、拾取物与表现场景
- `debug/player_sandbox.tscn`：A 工作的玩家独立验收场景，不进入正式流程
