# 五角场热线

Godot 4.7 俯视角肉鸽动作课程项目。三人团队开发，Windows 键鼠为首要目标平台。

当前已包含可运行的战斗基础切片：玩家、三种武器、四种移动方式、敌人、房间生成、方向格挡/完美格挡、HUD、VFX 池和持久场景容器。全部表现均为脚本与 Godot 基础节点占位，没有加入美术素材。

## 运行原型

使用 Godot 4.7.2 打开工程并运行主场景。默认操作：

主入口现为 `scenes/bootstrap/warehouse_main.tscn`：先进入安全仓库，靠近储物箱按 E，点击左侧装备存入、右侧装备取出到背包；箱子不限容量，背包上限 6 格，绑定初始装备不能存入。E / Esc / Tab 关闭箱子，Tab 打开配装背包。靠近右侧行动入口按 E 出击，撤离结算后选择“返回仓库”。装备自动保存，重启保留。新存档箱子为空，战利品从行动中带回。

背包现有独立 1 格黑匣，默认携带断路保险核心。将物品直接拖到黑匣即可存入或交换，拖回背包即可取出；主副武器和机动槽也支持拖放；黑匣内容死亡保留，不占普通六格。保险核心只有位于黑匣时生效，取出再放回不刷新次数。

原 `scenes/bootstrap/main.tscn` 仍是直接进入战斗的调试入口。仓库的存档与验证说明见 `docs/technical/仓库储物箱实施说明.md`。

- WASD 移动，鼠标瞄准；
- 左键攻击，右键格挡，滚轮切换武器；
- Space 使用机动能力；
- 1～4 切换步行、轮式、四足和飞行。

## 开发约定

- 游戏代码、场景和资源分别放入 `scripts/`、`scenes/`、`resources/`。
- 美术和音频原始素材放入 `assets/`。
- 第三方插件只放在 `addons/`，不在业务代码中直接散布修改。
- 业务代码通过项目内适配层访问背包、存档和音频插件，减少后期替换成本。
- 禁止直接更新已固定版本的插件；升级前先建立独立分支并运行回归测试。

## 导电与环境交互试验

打开 `scenes/debug/electric_reaction_sandbox.tscn` 按 F6：导电枪命中标靶，Q 切电击枪触发连锁；配电箱靠近 E 领取房间增益，或攻击破坏放电。R 重置。规则与边界见 [实施说明](docs/technical/导电与配电箱实施说明.md)。
