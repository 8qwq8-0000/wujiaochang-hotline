# 五角场热线

Godot 4.7 俯视角肉鸽动作课程项目。三人团队开发，Windows 键鼠为首要目标平台。

## 项目入口

- 策划案：`docs/design/五角场热线_开发流程策划案.md`
- 项目结构：`docs/technical/项目结构.md`
- 第三方依赖：`docs/technical/THIRD_PARTY.md`
- 素材许可：`docs/legal/素材来源与许可.md`

## 开发约定

- 游戏代码、场景和资源分别放入 `scripts/`、`scenes/`、`resources/`。
- 美术和音频原始素材放入 `assets/`。
- 第三方插件只放在 `addons/`，不在业务代码中直接散布修改。
- 业务代码通过项目内适配层访问背包、存档和音频插件，减少后期替换成本。
- 禁止直接更新已固定版本的插件；升级前先建立独立分支并运行回归测试。
