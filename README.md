# 五角场热线

三人团队开发的 Godot 俯视角搜打撤肉鸽动作课程项目。

铁人叛乱后的上海，五角场公共频道被自称“大肥鱼”的智能体刷屏。玩家接受 AI 接线员的委托，进入失控机械占据的楼宇，在战斗中回收组件、组合配装，并选择撤离或继续登楼，最终挑战楼顶 DS 中枢。

## 当前内容

工程已接入像素美术、战斗音效与音乐，包含主菜单、仓库存取与存档、双区域战斗楼层、第三层单区域突袭、撤离结算和楼顶 Boss。配装系统包含主副武器、防御装备、局内义体，以及人格与天赋；仓库另有合成师、图鉴和盾反训练。

正式普通地图池包含错位公寓、装卸车间、货运中庭、双轨货运站，前两层各组合两个不同区域，第三层为单区域。详细规则与阶段变更见[文档导航](docs/README.md)。

## 打开工程

1. 安装团队固定的 **Godot 4.7.2 Stable .NET**；环境配置见[项目开始准备清单](docs/setup/项目开始准备清单.md)。业务代码使用 GDScript，Compatibility 渲染器。
2. 克隆或下载仓库，用 Godot 导入根目录的 `project.godot`。
3. 按 **F5** 运行，主入口为 `scenes/ui/start_menu.tscn`。选择继续存档，或开始新存档并完成角色确认。
4. 进入仓库后调整配装，靠近行动入口按 **E** 出击。

内部画布为 640×360，默认窗口为 1280×720。不要只复制场景文件运行；工程依赖仓库中的字体、资源、数据和插件。

新存档先进入剧情序章“首次接线”，先看背景对话并确认出发，无枪入场，先用突进、再用盾反依次击杀敌人，再拾取手枪并按 Tab 装备。装备后直接认识炸药箱与增益箱。热量融入实际战斗，首次热量偏高或过热时短暂提醒，不暂停、不要求打到过热。领取入口增益后开始手枪波次，随后回收装备、与 Codex 对话并合成，击败小 Boss 后自动传送到仓库休整。序章通信期间暂停游戏，按 Enter 或点击对话框继续，读完才恢复行动。完成教学目标后自动推进、开启通道，按一次 Esc 跳过当前教学步骤；按住右上角跳过按钮 1.2 秒直接进入仓库。“继续游戏”不重播序章，详见[剧情序章说明](docs/technical/剧情序章与基础教学实施说明.md)。

## 基本操作

| 输入 | 操作 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 鼠标左键 / 右键 | 攻击 / 方向格挡，准确时机触发完美格挡 |
| Space | 固有突进；有移动输入时沿输入方向，否则沿瞄准方向 |
| Q / 鼠标滚轮 | 切换主副武器 |
| E | 拾取、交互、使用出口 |
| Tab | 打开配装背包 |
| Esc | 关闭当前界面或打开暂停菜单 |

仓库储物箱支持存入与取出装备，背包为六格，黑匣为独立保护格。义体在单次行动内跨层保留，撤离或死亡后清除；具体生命周期见[固有突进与义体说明](docs/technical/固有突进与义体迁移实施说明.md)。

设置页提供视频、音量、警戒难度等选项。试玩时直接按 F8（Mac 通常为 Fn＋F8）启用测试并开合面板，可领取装备、选择人格天赋或跳转关卡，也可直达普通或携带核心的 Codex 通道。F8 与 Esc 收起面板后继续当前关卡；点击“结束测试”才返回主菜单并结束测试。测试模式的变动仅在本次测试内保存，关闭后返回主菜单并恢复正式存档，详见[测试模式说明](docs/technical/测试模式实施说明.md)。

## 开发与验证

| 目录 | 内容 |
|---|---|
| `scripts/`、`scenes/`、`resources/` | 游戏逻辑、场景与资源数据 |
| `assets/` | 游戏使用的美术、字体与音频 |
| `art_sources/` | 素材源文件、生成草稿与制作记录 |
| `data/`、`shaders/` | 数据文件与着色器 |
| `addons/` | 第三方插件 |
| `tests/`、`tools/` | 自动化检查与开发工具 |
| `docs/` | 策划、技术、许可、汇报及历史记录 |

完整目录边界见[项目结构](docs/technical/项目结构.md)。测试方法与覆盖范围见[测试说明](tests/README.md)，例如在工程根目录运行：

```sh
godot --headless --path . --script res://tests/run_unit_checks.gd
```

`godot` 需指向本机 Godot 4.7.2 可执行文件。历史验收结果与已知限制保留在相应实施记录中，不能等同于当前版本的完整回归结果。

第三方插件保持固定版本，业务定制通过项目内适配层接入。依赖与素材使用范围见[第三方依赖](docs/technical/THIRD_PARTY.md)和[素材来源与许可](docs/legal/素材来源与许可.md)。
