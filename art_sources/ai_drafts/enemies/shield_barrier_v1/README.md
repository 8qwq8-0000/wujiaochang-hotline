# 盾兵前向技能屏障美术

用户范围：先生成技能屏障美术；技能屏障能阻挡玩家子弹，具体玩法逻辑尚未在本次实现。

- `shield_barrier_solid_v1.png`：第一版机械实心盾墙，保留作设计历史。
- 修订方向：用户要求更接近盾山大招的半透明技能屏障。中央采用可透视的浅蓝能量面，减少实体甲板，保留少量深蓝机械发射器、银色包边及橙黄色识别灯。
- 生成方式：内置 image_gen，输出透明 PNG；未覆盖现有盾兵或运行图集。

参考：[盾山技能中的展开巨盾形态](https://news.17173.com/z/pvp/content/12262022/191013934.shtml)。参考仅用于形态与用途，不依赖该旧版资料的当前技能数值。
