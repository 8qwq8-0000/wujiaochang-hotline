# 楼顶女神技能动画草稿 v1

2026-11-04，使用内置 ImageGen，以现有 `standing_v1/rooftop_goddess_standing_v1.png` 为参考编辑生成。三组均为正面施法，不包含新战斗逻辑、伤害判定或关卡接入。

- `echo/`：回声落点的角色吟唱。低头靠近幼鲸，胸前声纹形成、扩散、消失。
- `halo/`：光环裁断的施法。光环逐段点亮，集中释放后恢复。
- `protect/`：护子震波。轻微侧身、抱紧幼鲸，腰部释放一圈能量后复位。

每组保留生成原图 `source_sheet_4x2.png`、8张384×512透明PNG切帧、深色背景 `preview.gif`、透明 `transparent.webp` 和二值透明 `transparent.gif`。游戏素材应采用PNG，以保留半透明边缘。

`skills_preview.gif` 从左至右为回声、光环、护子震波。GIF循环仅用于比较动作，技能本身按一次性施法设计。当前播放时长为预览参数，尚未确定实际战斗时序。地面落点、平行光带等场地效果不包含在角色帧内。

`generation_prompts.json` 保留完整生成提示词。`export_previews.py` 负责切帧和导出，保留生成像素及alpha。已检查尺寸、帧数、透明通道及可见主体边界，三组均为8帧且主体未超出单帧画布。

AI生成的序列在衣褶、发丝及手部细节上仍有逐帧波动，属于动作草稿，尚未做游戏内观感或完整战斗验收。未生成独立受击、死亡动画；未改动现有游戏代码及一结局流程。
