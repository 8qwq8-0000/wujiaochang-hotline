# 石墨灰与琥珀 UI 素材样稿

状态：**仅供审阅，尚未接入游戏。替换现有 UI 前须先询问用户。**

## 已确认的设计

- 大面使用低饱和石墨灰；正文用暖灰白；琥珀只用于选中、能量传导和局部状态。
- 主面板共用一套哑光钢制小切角边框。
- 耐久保留现有逐格方块，仅用简洁底座和端头承托。
- 义体执行序列使用钢制导轨，支持四、五、六槽。传导进度与当前槽位由游戏动态绘制。
- 战斗 HUD 减少文字提示；设置页使用左侧分类、右侧设置项，短标题、短选项。

## 生成提示词摘要

- 统一边框：透明中心的正视角可缩放边框，哑光石墨钢、小切角、轻微磨损，仅两处极小琥珀标记；无文字、霓虹和 CRT。
- 耐久底座：细长金属凹槽与两端端头，中段可延长；不预绘分格、数值或填充。
- 能量导轨：单条横向钢制传导轨，中段均匀可延长，暗铜色未点亮通道；不预绘槽位。
- 义体槽框：单个正视角透明中心金属框，底部一处未点亮接点，可重复四至六次。

## 预览与接入边界

运行 `tools/ui_preview_project/preview.gd` 会在 `docs/art/validation/ui_graphite_amber_v1/` 输出带 `clean` 文件名的战斗、设置和四至六槽对照图。预览为静态排版验证，并非运行时 UI。旧的无 `clean` 文件名预览已过时，不作设计依据。导轨在正式接入时应采用可延展底层与重复单槽组合，保留动态槽数、图标、能量与执行状态；不要使用废稿或把六槽图片整体拉伸。

正式接入前还需检查九宫格边距、不同窗口尺寸、真实游戏状态与控件交互。新 PNG 草稿未放进 `assets/art/ui`，也未在现有面板脚本中引用。
