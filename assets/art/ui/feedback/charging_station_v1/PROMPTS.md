# Charging station popup art v1

Generated with the built-in image_gen tool. Integrated in PowerBox: successful claims show the matching arcade popup for 1.3 seconds, with a room-clear expiration caption. Animation pauses with the game.

## 攻速 +25%

Use case: stylized-concept. Asset type: transparent PNG arcade pixel typography sprite for a brief charging-station buff popup in a dark top-down pixel action game.
Create ONE isolated horizontal text sprite. Exact text, verbatim, one line: "攻速 +25%". Chinese characters and numerical percentage must be correct and very legible.
Match the project's existing PERFECT popup aesthetic: bold right-leaning italic block pixel lettering, stepped square-pixel contours, thick near-black dark navy outline, chunky down-left 3D extrusion, discrete 3-tone stepped highlights on letter faces. 1990s arcade action game reward lettering, confident energetic typography, clean and compact. Color palette: electric golden yellow, warm amber extrusion, pale lemon highlights. Add one small angular lightning bolt left of the text and just two tiny electric pixel sparks. Main focus is actual buff text and number, not decoration. Chinese lettering must have generously open counters, simple thick strokes and clear character structure, readable reduced to roughly 180-220 screen pixels wide.
Composition: wide centered wordmark, all elements fully within frame, compact vertical height and transparent padding around it. Genuine transparent alpha background. No rectangular panel, no scenery, no character, no sheet, no additional words, no subtitles, no watermark, no blurry bloom, no photographic elements, no smooth vector curves. Crisp pixel edges. This is a new art asset, not a screenshot or poster.
