# 场景部件与 GPT 合成师

内置 imagegen 生成/编辑的透明 PNG。使用新地图作为配色参考；GPT 使用用户明确指定的白发、紫角、龙翼、龙尾角色三视图作为身份参考，不使用此前网上搜到的 Logo 头形象。原始生成文件保留在 Codex generated_images 中，游戏引用当前目录副本。

- charging_terminal.png：深灰充电终端，青色电池屏、小闪电标识、侧面线缆。
- explosive_crate.png：橙色炸药箱、三支红色弹筒、警示条及红灯。
- bulkhead_closed.png / bulkhead_open.png：普通金属滑门闭合/开启两态；开启状态的门洞为真实透明。
- downward_elevator.png：加强门框、暖色灯带、向下箭头，与普通同层房门区分。
- gpt_synthesist.png：用户指定 GPT 形象的正面像素 NPC，保留白发、紫角、翼、尾和白紫服装。

提示词共同约束：工业科幻 2D 游戏素材，统一深灰蓝金属、左上受光、单独物体、透明 alpha、无白描边、无背景、无文字或素材板。各部件再指定上述用途与颜色。普通门开启态基于闭合图编辑，保持门框并移除门叶。GPT 提示词要求从用户截图提取中央角色设定，忽略手机黑边，保持身份特征并改为单一正面待机像素形象。

RefinedEnvironmentArt 仅控制绘制，沿用既有碰撞、伤害、互动与状态。领取/损坏的配电箱变暗，引爆后的完整炸药箱隐藏，普通门随 opened 切图，铰链门跟随既有 _swing 转角绘制，电梯随 enabled 变亮。self_modulate 只隐藏父节点旧占位绘制，不隐藏交互提示。素材有效轮廓区域已测量，避免宽透明边距和微弱 alpha 杂点影响缩放。
