# 武器命中音效 v1

生成日期：2026-10-22

这些运行时音效由项目自制 `player_hit.wav` 与 Kenney CC0 素材混合制作。原始包、许可证、下载 URL 和 SHA-256 记录位于 `art_sources/audio/third_party/kenney/`。

## 文件组

- `service_pistol_hit_*.wav`：自制主体 + Impact Sounds 的 `impactPunch_medium_*`。
- `scattergun_hit_*.wav`：自制主体 + `impactPunch_heavy_*` + Sci-Fi Sounds 的 `lowFrequency_explosion_*`。
- `rail_cannon_hit_*.wav`：自制主体 + `laserLarge_*` + `lowFrequency_explosion_*`。
- `material_light_metal_*.wav`：Impact Sounds 的 `impactMetal_light_*`。
- `material_heavy_metal_*.wav`：Impact Sounds 的 `impactPlate_heavy_*` + `impactMetal_heavy_*`。

全部文件均为 44.1 kHz、16-bit、单声道 WAV，并经过裁切、淡出和峰值限制。Kenney 素材采用 CC0-1.0；署名不是强制要求。
