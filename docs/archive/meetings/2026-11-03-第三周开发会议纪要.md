会议主题：第三周开发复盘、移动端适配进展、第二结局与整体美术优化安排


## 一、本周工作梳理

### 1. 新增与完善内容

1. 加入剧情序章和基础操作教学，串联突进、盾反、拾取、背包装备、环境交互、合成及首次进入仓库的储物引导。
2. 加入隔离测试模式，集中提供装备领取、人格与天赋选择、楼层及 Boss 跳转，减少分散测试入口对正式流程的干扰。
3. 完善遗产酒馆的档案展示，形成“遗产酒谱、人格档案、敌人图鉴”三个分页；敌人图鉴按实际遭遇解锁，并兼容旧存档。
4. 接入传令兵及相关动画与信号表现，调整楼层敌人强度递进和部分武器掉落权重，继续丰富后续楼层的战斗变化。
5. 推进手机端适配，增加虚拟摇杆、多点触控动作键、自动目标选择和按键布局编辑，并补充触屏对话、背包及手机操作提示。

### 2. 内容删减与调整

1. 收拢旧燃料沙盒、试验箱及 Boss 快捷测试等分散入口，改由隔离测试模式承担调试需求。
2. 调整仓库布局与出口表现；序章中的步骤衔接、暂停通信和首次入仓引导继续迭代，减少重复确认和操作中断。
3. 调整手机端背包布局、安全区和操作文案，增加触控关闭、滑动及长按拖放，适配手机上的实际操作方式。
4. 优化安卓预览包的打包范围，排除未使用字体和参考素材，保留游戏实际引用资源。

### 3. Bug 修复与稳定性工作

1. 针对序章步骤推进、正式敌人行为复用、环境箱介绍与交互、教学结束后返回仓库等环节补充修正和专项检查。
2. 修正手机端对话依赖电脑按键、背包缺少直观关闭入口、界面超出安全区及滑动误触等问题。
3. 补充敌人信号、动画、楼层难度、图鉴解锁、移动端操作、对话与背包等专项检查，并维护现有单元检查。
4. 完成安卓预览 APK 的签名和包结构校验；完成 iPhone 安装、启动及部分界面检查。上述结果不等同于完整真机通关或性能验收。

## 三、当前问题与下阶段重点

1. 现有主流程已有序章、普通楼层、服务通道、Boss 和仓库循环，下一阶段需增加有前置条件和过程变化的新路线，扩展可游玩的内容。
2. 场景、角色、敌人、界面及特效分批制作和接入，整体风格、比例、配色及细节完成度仍需统一，提升画面质感与辨识度。
3. 手机端已具备触控和构建基础，但仍需真实设备上的完整操作、连续游玩、后台恢复及性能检查。
4. 自动化检查和局部设备验证应与完整手动试玩区分，继续关注流程阻断、存档兼容、资源释放告警及新增路线对原结局的影响。

## 四、下周任务安排

### 1. 扩展游戏流程，增加第二结局及前置条件

1. 明确第二结局与原结局的剧情关系、触发方式及解锁前置条件，让玩家能理解新路线为何出现、需要完成什么。
2. 将新内容接入实际行动流程，补充必要的调查、任务节点、交互反馈及最终结局环节，增加过程中的玩法变化。
3. 明确路线选择后的推进规则、撤离限制、中断恢复及失败处理，保证提示与实际规则一致。
4. 完善新路线的通关记录、仓库回顾和旧存档兼容，保留原结局正常进入及完成的路径。
5. 完成新路线与原路线回归，检查解锁、任务推进、最终战、结局结算、死亡及恢复流程，并通过完整手动试玩评估节奏和难度。

交付目标：形成前置条件清楚、过程可游玩、结局可达成且能正确保存的新路线，配套流程说明与验证记录；已有本地实现继续完成整合与验收。

### 2. 全面优化美术风格，提升整体质感

1. 统一视觉方向，明确主色、辅助色、材质、光照、像素密度和界面层级，形成可供后续素材制作与接入遵循的标准。
2. 优化仓库、普通战斗区、服务通道和 Boss 场景的地面、墙体、道具、背景及空间层次，处理接缝、重复感和风格不协调的素材。
3. 统一角色与敌人的比例、脚底位置、动画节奏及武器挂点，改善移动、攻击、受击和死亡动作之间的衔接。
4. 梳理菜单、HUD、背包、档案及对话界面，统一字体、字号、间距、边框、图标和选中反馈，兼顾桌面与手机可读性。
5. 调整光效、粒子、弹丸、命中及预警表现，增加细节和氛围，同时保证敌人、掉落与危险区域清晰可辨。
6. 使用相同场景、相同显示条件的前后截图与实际运行效果进行对比，结合试玩反馈检查整体一致性、精致度和性能开销。

交付目标：提交统一的视觉规范、重点场景和界面优化、角色与特效修正，以及前后对比素材，使整体画面更协调、细节更完整、质感更成熟。
