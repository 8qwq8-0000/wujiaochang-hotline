# 《五角场热线》第十二周项目会议纪要

会议日期：2026年11月17日  
会议主题：进入测试阶段，修复问题、改善操作手感并完成提交前打包收尾  
记录依据：远端 `origin/main` 于 2026年11月11日至17日合入的提交及版本说明

## 一、本周项目进展

项目已从集中开发转入测试与交付整理阶段。本周重点围绕完整游玩流程、战斗操作反馈、移动端体验和多平台导出展开，同时补充了发布前的回归检查。Windows 与 Android 已整理 `v0.2.0` 版本；macOS 已准备通用预览包，但仍需 Mac 实机验证。

### 1. 问题修复与回归检查

1. 修正新手引导和补给台流程中的交互问题，处理背包合成、交互边框、敌人掉落导航及退出清理等缺陷，减少流程中断和界面残留。
2. 调整义体线路、初始开火资源识别、战斗义体交互及整备大厅布局，修正分辨率变化后场景门位置异常等问题。
3. 修复 Android 自动射击与手动长按开火之间的输入冲突，使手动操作保持独立；补充移动端控制、仓库及义体相关检查。
4. 扩展 Boss 表现、退出流程及发布旅程的集成检查，更新发布检查清单，并补充资源 UID 记录，降低导出时的资源引用风险。

### 2. 操作手感与表现优化

1. 优化战斗义体的操作反馈、线路提示和控制提示，让玩家更容易判断当前可用操作与战斗状态。
2. 强化双 Boss 战斗的声画反馈与转场表现，调整弹丸、重力波及相关战斗效果，提高攻击预警和命中反馈的辨识度。
3. 调整整备站空间布局、战斗 HUD 和部分对话提示，改善战斗与整备之间的操作衔接。
4. 在主菜单加入玩家反馈问卷入口，便于收集预览版试玩意见，为后续手感调整提供依据。

### 3. 打包与提交前收尾

1. 完成 Windows 与 Android `v0.2.0` 的版本配置、图标、导出内容和发布说明整理；核对 Android APK 的版本、签名及正式包内容，排除测试工具界面和调试场景。
2. 配置 macOS Intel 与 Apple 芯片通用导出预设，并整理第二版预览包说明；已在 Windows 环境检查导出包的架构、版本和资源内容。
3. 补充发布回归脚本与测试说明，检查主流程、退出清理、移动端控制和义体相关功能，为最终提交留存可追溯的验证依据。

## 二、目前仍需处理的问题

1. 继续进行完整手动试玩，重点排查序章、战斗、Boss、结算与返回整备大厅的连续流程问题；自动化检查不能替代实际游玩验收。
2. 在 Android 实体设备上验证自动射击、手动瞄准、长按开火、触控布局及性能表现，根据试玩反馈继续微调手感。
3. 在 Mac 实机验证通用预览包的安装、启动和游玩，特别检查 Intel Mac；当前仅完成 Windows 环境下的导出与包体检查。
4. 汇总反馈问卷和测试记录，对阻断流程、影响操作或明显影响观感的问题优先修复，并在修复后复测对应平台。

## 三、下阶段安排

1. 建立问题清单，按“阻断流程、影响操作、一般表现”排序，记录复现步骤、修复提交和复测结果。
2. 以实际设备试玩为依据继续调整战斗节奏、输入响应、提示时机和 Boss 反馈。
3. 完成最终版本的全流程回归、导出包安装检查、版本号及文件清单核对，整理作品介绍、展示材料与提交文件。
4. 提交前冻结交付包，对照发布说明确认各平台包体与仓库提交一致，并保留未验证事项的说明。
