- 车间、仓库、门、炸药特效、装备图标、炮台、人格、广告及 Boss 等生成素材：生成记录分布于 `art_sources/ai_drafts/`、`docs/art/` 和 [AI 使用日志](../AI_USAGE.md)。这是来源记录，不能单凭“AI 生成”推定输入参考或任何发布用途均已获授权。
- 当前玩家身体引用 `placeholder/gemini_motion_v1/`，盾反动画及部分方向有独立生成记录；旧文档笼统的 `placeholder_player_*.png` 不等于当前全部玩家素材。具体缺口见下表。

## 署名与交付

- 根目录 [ATTRIBUTION.md](../../ATTRIBUTION.md) 是来源与署名说明，不声称游戏已经实现 credits 菜单。
- 根目录 [THIRD_PARTY_NOTICES.txt](../../THIRD_PARTY_NOTICES.txt) 汇集当前可确认的引擎、插件、运行字体及音效许可，作为随包文档候选；它不解决上表未知资源的授权问题。
- Godot 官方接受在游戏文档或 credits 中提供官方许可页链接；此处同时保存了 4.7.2 的许可及版权清单。详见[官方说明](https://godotengine.org/license/)。
- Maaack 模板中的 Git 图标自带许可为 CC-BY-3.0，Godot 图标为 CC-BY-4.0；已纠正旧文档将 Git 图标写成 GPL 的错误。模板示例素材是否在最终包内，仍需以实际包内容核对。
- 原文中仅列作计划的 Phantom Camera、Trauma、Health/HitBox、Juicee、Lootie、Vision Cone、Beehave 等未在当前 `addons/` 中安装，不再列为已使用资源，也不补造版本。

## 项目生成素材

本节按素材用途登记来源。具体生成日期、提示词和制作过程保留在对应原始记录中；测试结果见实施说明与 AI 使用日志。

### 举旗传令兵

2026-10-29 通过内置 image_gen，以用户确认的持旗概念和工程现有远程兵为参考生成独立动画图集，正式资源为 `assets/art/characters/enemies/animated/signal_herald_v3.png`。概念、提示词见 `art_sources/ai_drafts/enemies/signal_herald_v3/`，分帧对齐与预览见 `docs/art/validation/signal_herald_v3/`。这是本次新增素材的来源记录，不改变旧参考素材原有的来源和许可状态。

### 仓库场景与设备

- 场景组件、四向墙体、转角及立体设备：内置 image_gen 根据项目确认的地下维修安全屋方向生成，资源位于 `assets/art/environment/warehouse/`。原始生成记录见 [warehouse_safehouse_v1](../../art_sources/ai_drafts/warehouse_safehouse_v1/)，包含 `components_prompts.json`、`supplemental_prompts.json`、`walls_v2_prompts.json`、`foreground_corner_prompts.json` 和 `props_v2_prompts.json`。
- 东墙出击门 `elevator_east_v3.png`：以项目已有出击门为参考生成侧向版本，提示词见上述目录的 `elevator_east_v3_prompt.json`。
- `concept_v1.png` 是场景概念参考，不作为正式地图背景贴图。合成师复用 `assets/art/environment/refined/gpt_synthesist.png`，来源见[场景部件与 GPT 合成师美术说明](../technical/场景部件与GPT合成师美术实施说明.md)。

### 战斗场景建筑

- `assets/art/environment/combat_architecture/door_horizontal_v1.png`、`door_vertical_v1.png`：内置 image_gen 以项目已有 `bulkhead_closed.png` 为材质参考生成，提示词见 [combat_architecture_v1/prompts.json](../../art_sources/ai_drafts/combat_architecture_v1/prompts.json)。
- 围墙、转角复用仓库素材，地板与掩体复用 workshop 素材；运行时以 AtlasTexture 和最近邻采样组织显示。

### 爆炸与碎屑特效

`assets/art/effects/bomb/explosion_sheet_v1.png`、`debris_sheet_v1.png` 由内置 image_gen 以项目已有 `explosive_crate.png` 为材质参考生成，分别包含八帧爆炸烟雾与八种碎片。原始 PNG 保留，Godot 通过 AtlasTexture 分格使用。提示词见 [bomb_effects_v1/prompts.json](../../art_sources/ai_drafts/bomb_effects_v1/prompts.json)。

### 程序绘制与派生法阵

- 充电台法阵由 `scripts/presentation/charging_sigil.gd` 使用 Godot 几何绘制和透明度动画生成，没有新增外部图片或字体。
- `assets/art/effects/warehouse_sigils/*_complete.png` 从项目已有法阵的几何渲染中提取半图，经透明背景恢复和镜像补全制成；原始半图、渲染代码快照和处理说明见 [warehouse_sigils_extracted_v1](../../art_sources/ai_drafts/warehouse_sigils_extracted_v1/)。


### 普通层隐藏房

工业祭台和残损通信核心由内置 imagegen 以普通车间场景为美术参照生成，来源记录及运行时裁切方式见 [hidden_shrine_v1/README.md](../../assets/art/environment/hidden_shrine_v1/README.md)。场景与通道复用现有普通层地板和建筑纹理。旧 room.png 为未接入的概念背景。
