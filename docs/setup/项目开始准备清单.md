# 项目开始准备清单

## 必需环境

- 使用团队固定的 **Godot 4.7.2 Stable .NET**，不要用旧版引擎覆盖导入结果。
- 工程业务代码为 GDScript，渲染器使用 **GL Compatibility**；导入入口是仓库根目录的 `project.godot`。
- 首次导入需要等待字体、贴图和插件资源扫描完成，再运行主场景。

## 首次运行

1. 克隆或下载完整仓库，不要只复制单个场景。
2. 在 Godot 项目管理器中导入根目录的 `project.godot`。
3. 确认编辑器没有脚本或资源加载错误，然后按 F6 检查当前场景，或按 F5 从主菜单进入完整流程。
4. 自动检查命令见仓库根目录 [README](../../README.md#检查)。其中的 `godot` 需要指向本机 Godot 4.7.2 可执行文件。

## 提交前

- 不提交 `.godot/`、个人编辑器布局、临时截图、导出产物或本机绝对路径配置。
- 新增第三方素材或插件时同步更新许可清单；新增玩法时同步更新对应实施说明和专项检查。
- 提交前至少确认工程可导入，并运行与本次改动直接相关的专项检查。
