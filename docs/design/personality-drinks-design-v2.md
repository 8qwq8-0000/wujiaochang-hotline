# 三种主人格饮料设计 v2

> 状态：2026-10-20 共识版  
> 完整系统规则见 `portable-ai-personality-spec-v2.md`

## 1. 共用规则

- 饮料不是装有人格意识的液体，而是“神经同步剂＋一次性实体授权密钥”。
- 人格模型已加密存放在本地接线员分支中；饮用完成一次装载、切换或升级，并使密钥不可复用。
- 每次兑换必须在当前楼层整备处立即饮用，离开整备处后未使用的授权失效。
- 同款首次饮用装载一级人格，再次饮用升至二级、三级；切换离场不会清除本局等级。
- 满三级后仍可饮用同款以维持当前人格，但不会继续升级或返还其它战斗资源。
- 三瓶只决定人格与等级，不进入普通背包，不带随机词条，不与武器、义体或防御组件合成。
- 通关生成的遗产饮料仅是无属性记录，不改变三瓶主人格饮料的能力。

## 2. 深渊忍者：赤黑余烬

- 战斗主题：猎痕、追击、连杀、夺身猎步。
- 容器：矮而宽的黑色陶瓷瓶，轮廓接近兜帽覆盖下的面甲。
- 识别色：暗红与墨黑。
- 识别图形：向中心收缩的斜裂纹与眼形负空间。
- 味觉叙事：烟熏乌梅、短促辛辣、矿物感和持续回苦。
- 等级表现：一级一道红裂；二级裂纹分叉；三级形成不闭合的赤红眼轮。
- 物品短句：**标记猎物，击杀共振**。
- 物品文案：瓶底有东西在敲。它知道门从哪一边打开。

饮用时压碎一段黑色封缄环。视野边缘出现向内收缩的红色裂纹，头像最后亮起一只眼。不得使用血液飞溅图案。

## 3. 传奇宗师：向山难越

- 战斗主题：观察、解析、格挡验证、代行拆招。
- 容器：细长透明双腔瓶；开瓶后无色与青蓝液体沿刻度槽混合。
- 识别色：青蓝与冷白。
- 识别图形：同心标尺、校准线与永远保留缺口的几何环。
- 味觉叙事：冷萃乌龙、青柑、轻盐矿泉感、白胡椒和短促茶涩。
- 等级表现：一级基准线；二级轨迹环；三级预测网格，始终保留开放缺口。
- 物品短句：**观察招式，格挡验证**。
- 物品文案：配方每次完全相同。变化的是喝下它的人。

饮用时先旋转瓶颈完成双腔混合。视野出现三组对齐线，最后一组偏离半格，随后由接线员完成校正。

## 4. 摇滚奇侠：龙舌兰

- 战斗主题：持续火力、舞台反馈、热量与换枪节奏。
- 容器：矮款杯，琥珀色龙舌兰酒液、薄泡沫、红辣椒装饰和仿效果器机械杯托。
- 识别色：酸黄与炭黑。
- 识别图形：音频波形、舞台反馈尖峰与音量旋钮刻度。
- 味觉叙事：烘烤龙舌兰、焦柑橘、苦精、辣椒热感和持续发麻。
- 等级表现：一级细波形；二级失真重影；三级完整反馈冠。
- 物品短句：**持续开火，积累反馈**。
- 物品文案：坏主意也得有节拍。好主意通常只是活得更久的坏主意。

饮用时拨开红辣椒，酸黄色波形横扫界面并在越界前突然断开，头像从断点处显现。不得使用现有乐队标志。

## 5. 缩略图与可访问性

- 64 px 图标用于整备处主选择；32 px 图标用于行动记录和紧凑列表。
- 深渊忍者必须保留黑色矮瓶、红色斜裂和眼形负空间。
- 传奇宗师必须保留透明细瓶、双腔结构和青蓝同心刻度。
- 摇滚奇侠必须保留矮杯、琥珀酒液、红辣椒和失真波形杯托。
- 三瓶不能只靠颜色区分；斜裂纹、同心标尺、波形尖峰是固定的非色彩识别符号。
- 现有候选图位于 `assets/art/items/personality_drinks/`；预览和源参考位于 `art_sources/ai_drafts/ai_personalities/v1/`。

## 6. 遗产饮料外观

遗产饮料沿用玩家通关时最后使用的人格瓶型，但追加不可拆卸的黑匣吊牌。吊牌只显示通关日期、行动代号和核心统计图标，不提供任何属性词条。酒谱展开页再显示完整行动记录。

## 7. 发行风险

三瓶仍保留原型角色的稳定视觉与性格暗示。“向山难越”直接包含原型姓名关联，“龙舌兰”与头像也具有明显识别性。公开发行前必须单独审查角色著作权、作品元素与真人肖像风险；本文件不将“致敬”视为授权依据。
