# 赛博朋克 UI 视觉基线

> 状态：2026-10-15 已达成共识  
> 适用范围：战斗 HUD、背包、暂停、设置、撤离结算及后续协议终端  
> 可运行样板：`res://scenes/ui/showcase/cyber_ui_showcase.tscn`

## 1. 核心定位

UI 是“上海楼宇应急通信终端”，不是紫粉色夜店式赛博朋克。所有界面共用荧光绿 CRT 操作系统语言：硬直角切角框、像素网格、分段仪表、终端命令式焦点和少量中英文系统标签。中文是主要信息，英文只作为小型设备标签。

画面不能依赖外部 UI 美术素材。边框、仪表、准星、扫描线与事件故障均由 Godot Control、`_draw()` 和 Shader 生成。

## 2. 固定画布与字体

- 逻辑画布固定为 `640 × 360`，目标显示为 16:9 整数倍缩放，不为其它比例重排组件。
- 正文使用 Ark Pixel Font 简体中文等宽版：`ark-pixel-12px-monospaced-zh_cn.ttf`。
- 正文 12 px，标题 16 px，英文微型标签 10 px；控件、边框与文字落在整数坐标。
- 首次进入只播放约 1.2 秒启动序列，任意输入可跳过；普通页面切换控制在 120～180 ms。

## 3. 固定色板

| 语义 | 色值 | 用途 |
|---|---|---|
| 背景 | `#04100D` | 主画布 |
| 面板 | `#071A16E8` | 半透明终端面板 |
| 主色 | `#72FF9A` | 正常状态、主边框、可操作项 |
| 暗色 | `#286B45` | 次要刻度、非焦点控件 |
| 高亮 | `#D8FFE2` | 成功、完美格挡、关键确认 |
| 警告 | `#FFC857` | 过热、警戒、临界状态 |
| 危险 | `#FF4055` | 伤害、致命风险、系统故障 |
| 弱化 | `#7FA890` | 说明文字、不可用项 |

颜色承担固定语义，不得为了装饰随意交换。正常为绿、警告为琥珀、危险为红、成功为近白绿。

## 4. 战斗 HUD

- 四角仪表模块围绕战斗视野布置：左上机体、右上任务、左下机动、右下火控；中央保持无遮挡。
- 耐久、热量、接管次数、机动充能、警戒等数值使用分段仪表，不使用普通连续进度条。
- 准星使用极简分段圆环；目标锁定只显示角标，不显示敌人血条、穿墙轮廓、雷达或小地图。
- 非战斗状态 HUD 整体降至约 40% 亮度，但耐久、武器和必要提示保持可读。
- 伤害、格挡、过热和 AI 接管通过线路脉冲、面板状态和短时事件故障表达，不使用长期全屏闪烁。
- AI 在界面中只显示为“接线员”及链路状态；协议带来的措辞差异仅作为对话彩蛋，不显示人格或性格标签。

## 5. 提示队列

- 底部中央最多同时显示 3 条带边框的终端消息。
- 普通消息采用短展开/打字效果；紧急消息立即出现。
- 同类重复消息合并，接管通讯优先于普通提示。
- 每条消息必须有嵌入式标题、语义色边框和单句正文，不能遮挡准星与武器模块。
- 键位提示使用有边框的终端键帽形式，并读取当前输入映射，不写死按键名称。

## 6. 工作区界面

- 背包、暂停、设置和撤离结算共用同一套终端工作区，不使用风格割裂的弹窗。
- 背包固定为 2×3 普通格，装备槽居中，右侧为诊断面板；不使用漂浮式 Tooltip。
- 菜单用 `>` 表示当前终端命令，但保留 Godot 标准按钮、滑杆、选择框和键盘/鼠标命中区域。
- 设置页必须包含分辨率、总音量、音乐、音效、警戒难度，以及 CRT 三级：关闭／低／标准；默认“低”。
- CRT 只覆盖 UI；只有受击、过热、高警戒或 AI 接管等事件允许极短的全屏故障。
- UI 音效以后使用程序生成的短提示音，不引入新的外部音频素材。

## 7. 可复用组件

首版组件库位于 `scripts/ui/`：

- `CyberUITheme`：色板、字号、控件外观和类型变体；
- `TerminalPanel`：1 px 硬切角边框、嵌入标题和刻度；
- `TerminalNotice`：提示队列单元；
- `SegmentMeter`：通用分段仪表；
- `CRTOverlay`：关闭／低／标准三级和短时事件故障；
- `CyberUIShowcase`：可运行的战斗页、设置页和启动序列样板。

首轮仅审批可复用视觉样板，不直接替换现有战斗 HUD、背包或菜单。视觉通过后再分模块接入真实数据和输入。

## 8. 性能与可访问性

- 以 Godot Compatibility 渲染器稳定 60 FPS 为目标，只使用一层统一 CRT Overlay 和轻量控件发光。
- 默认低强度扫描线与噪点；标准档也不得牺牲文字辨识度，关闭档必须完全去除 CRT 效果。
- 禁止持续抖动、持续色差、屏幕弯曲和滚屏。事件故障必须短暂且可预测。
- 所有关键状态不能只靠颜色区分，必须同时有标题、数值、分段或文本变化。

## 9. 外部参考与许可

CRT Shader 参考 `JoshuaJRideout/godot-crt-shader`，固定 commit `165809c5c4e321786e2481bddc739f072476df62`，MIT。项目版本删除了弯曲、滚屏和色差，只保留可调扫描线、噪点、轻微闪烁与事件故障；许可副本位于 `docs/legal/third_party/godot-crt-shader-LICENSE.txt`。
