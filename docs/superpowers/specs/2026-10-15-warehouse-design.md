# 仓库与储物箱

用户已确认：安全仓库场景、靠近按 E 打开箱子、双栏装备存取、自动保存、出击入口和撤离返回。

- 项目入口通过继承 Main 的 warehouse_main 场景进入仓库，原 Main 保留战斗入口以兼容调试与回归。
- WarehouseStore 保存版本化 JSON：箱内物品和仓库随身配置。写临时文件后原子替换；读写失败向玩家提示并阻止覆盖或转移。
- 玩家与箱子转移完整 GLoot 实例数据。箱子无容量限制，取出只进入六格背包；绑定初始装备禁止存入。装备槽物品可以直接存入，装备控制器同步刷新。
- 出击前保存箱子并移交随身物品到当前行动，磁盘仓库随身配置清空，避免强退复制。撤离回仓时保存完整带回配置；行动中的物品不提前进入永久仓库。
- 仓库内换装与箱子存取即时保存。箱子 UI 暂停世界，Esc/E/Tab 或关闭按钮退出，关闭恢复原暂停状态。
- 场景使用现有基础节点和程序绘制占位素材，保持 640×360 的项目规格。存档位于 user://warehouse.json。

验证：真实 E 键交互、双向转移、满包拒绝、绑定物品拒绝、实例属性保留、保存失败回滚、重启读取、仓库出击与撤离回仓，以及原有单元/背包/撤离回归。
