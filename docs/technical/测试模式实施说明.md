# 测试模式实施说明

## 使用入口

游戏窗口内按 F8（Mac 通常为 Fn＋F8）直接启用隔离测试并打开面板，无需在设置页开启。之后 F8 仅切换面板显示；Esc 收起面板继续当前关卡，测试模式和配装保持。右上角按钮也可重新打开面板。只有点击“结束测试”才结束隔离测试、恢复正式档案并返回主菜单。

关卡跳转位于面板左侧，提供“直达 Codex 通道”和“通道＋二结局核心”。前者保留当前测试配装；后者确保携带实际核心、在隔离档案中补齐路线条件，能触发 Codex 同行新对话。背包满时提示空出一格，不丢弃或覆盖现有装备。

## 支持的操作

- 领取正式武器、义体、防御装备及保险核心。武器和防御可选择制式、改良、原型品质。人格绑定武器仍通过对应人格获取，退役和内部调试道具不进入领取目录。
- 六格背包与保险核心唯一限制继续生效，领取失败不覆盖已有物品。关闭面板后使用 Tab 配装。
- 自由选择人格、1 至 3 级及各级天赋，选择完整验证后一次应用，不消耗人格饮料。
- 跳转测试仓库、三层普通关卡或楼顶 Boss。跳转保留当前测试配装、重置关卡并回满生命；普通层的直接跳转不强制打开人格饮料界面。
- 一键清理整个普通楼层，包括尚未激活的战斗区域。敌人仍发出正常的击败、掉落和清场事件，重型敌人直接完成死亡，不等待自爆。
- 直接击败 Boss，支持休眠、苏醒和守卫护盾阶段。出口和通关结算仍使用原有流程，可测试遗产记录展示。

## 存档隔离

`GameSettings` 创建常驻的 `TestTools` 面板，不修改项目自动加载配置。开关不持久化，程序重启后默认关闭。

`WarehouseStore.begin_test_session()` 保留进入前的正式档案快照。测试中的 `commit()` 继续校验装备与唯一实例 ID，但只更新内存，不创建、替换或重命名存档文件。测试中新建档案也不备份或覆盖正式文件。仓库、撤离、死亡、图鉴和通关记录共用这层隔离。

关闭测试模式会卸载当前游戏场景，恢复正式档案与原难度，再进入主菜单。恢复的正式档案在新主菜单读取之前生效。测试配装与记录不会带回正常游戏；本次测试关卡也不会续接为正式行动。请从仓库或主菜单进入测试，避免把尚未结算的正式行动当作已保存进度。

## 验证

新增集成检查：

```sh
godot --headless --path . --script tests/integration/test_mode_check.gd
```

覆盖设置中移除开关、F8 直接启用及反复开合不返回主菜单、Esc 继续当前关卡、普通/核心通道跳转与同行对话、满背包不丢装备、领取品质与容量限制、三人格全部天赋分支、非法选择无部分修改、仓库与楼层跳转、整层清场、Boss 开场与护盾阶段快速击败、结算与新建档案隔离、主菜单直达 Boss、死亡后跳关恢复，以及退出后正式档案和存档字节一致性。

同时运行原有 `settings_menu_check.gd`、`warehouse_check.gd`、`victory_flow_check.gd`，并检查实际渲染的设置页和测试面板。当前测试过程仍出现 Godot 退出时的资源／ObjectDB／RID 警告，以及已有敌人素材 UID 回退提示；这些提示尚未作为本次功能的一部分修复。Windows 与重新导出的独立游戏包未验证。

本轮验证：测试工具专项 100 项通过（包含 F8 关闭面板后仍处于原游戏场景、重复开合、主菜单直达核心通道、满背包拒绝且不覆盖、完整会话后正式存档字节相同）；设置专项失败数 0，Codex 同行回归 45 项通过。窗口确认关卡及两种通道入口位于面板顶部，截图 `docs/art/validation/test_tools_f8/panel.png`。

## 2026-11-04 界面与图片更新

面板使用深蓝灰卡片，左侧为关卡跳转与清场操作，右侧分为装备补给、人格与天赋；底部固定操作反馈、快捷键提示和“返回游戏”“结束测试”。默认 640×360 逻辑视口下三个分区完整显示。

装备选择与下拉列表复用正式装备贴图；三个人格使用现有主菜单头像；18 个天赋使用新建的 SVG 技能图标，按人格分别用红、青、金色识别。选项切换同步图片，悬停显示天赋完整说明；高于所选等级的天赋仍保持禁用。SVG 图标位于 `assets/art/ui/test_talents/`。

新增“二结局 Boss”跳转，保留配装并补齐核心及同行前置，播放正式入场剧情；背包满时拒绝跳转。最新测试工具专项 105 项通过。另在窗口运行中逐项确认 11 件装备、三个人格头像、18 个天赋图标、切换、说明和等级禁用。截图：`docs/art/validation/test_tools_f8/panel_with_icons.png` 与 `equipment_dropdown_with_icons.png`。历史截图和断言数量保留作迭代记录，当前界面以上节为准。

主分支整合后，保留八种高级义体资源与效果，F8 专项新增实际领取、图片和模块身份检查，共 121 项通过；通信触屏推进与去重另有 18 项检查。整合与移动端回归见[整合记录](本地变更与PR准备说明_2026-11-04.md)。
