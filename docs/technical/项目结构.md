# 项目结构

```text
五角场热线/
├─ addons/                 第三方和编辑器插件
├─ assets/                 原始字体、美术、音频
│  ├─ art/
│  ├─ audio/
│  └─ fonts/
├─ data/                   JSON、CSV、本地化源文件
├─ docs/
│  ├─ design/              策划与玩法文档
│  ├─ legal/               素材来源、第三方许可证
│  ├─ research/            原始调研材料
│  └─ technical/           技术方案、依赖与结构说明
├─ resources/              可复用 Resource 数据
├─ scenes/                 Godot 场景
├─ scripts/                项目业务代码
├─ tests/                  自动化与规则测试
└─ project.godot
```

## 边界规则

1. `addons/` 中只保留上游插件代码；项目定制逻辑写在 `scripts/`。
2. 场景负责组合节点，算法和规则尽量写成可测试脚本或 Resource。
3. 预制战斗房间放在 `scenes/levels/rooms/`，抽取权重放在 `resources/rooms/`。
4. 组件基础数据、实例词条和存档结构分离，避免 UI 直接依赖 GLoot 内部实现。
5. `assets/fonts/` 内的非商用或许可未知字体不得用于公开发布版本。
