# 项目结构

```text
五角场热线/
├─ project.godot           Godot 工程配置，F5 从主菜单启动
├─ addons/                第三方与编辑器插件
├─ assets/                游戏使用的美术、字体与音频
├─ art_sources/           素材源文件、生成草稿与制作记录
├─ data/                  JSON、CSV 与数据源文件
├─ docs/
│  ├─ README.md           文档总导航
│  ├─ design/             策划、玩法与素材规范
│  ├─ technical/          系统实施说明、依赖与结构说明
│  ├─ art/                美术接入、参考与验收截图
│  ├─ legal/              素材来源与第三方许可证
│  ├─ presentation/       首版汇报、逐页讲稿、配图与立项参考
│  ├─ research/           原始调研与选型材料
│  ├─ setup/              环境准备与初期协作手册
│  ├─ team/               团队分工、素材登记与环境记录
│  ├─ archive/            历史会议、阶段清单及旧设计索引
│  ├─ superpowers/specs/  早期专项设计记录
│  └─ AI_USAGE.md         AI 辅助开发与验证记录
├─ resources/             可复用 Resource 数据
├─ scenes/                Godot 场景
├─ scripts/               项目业务代码
├─ shaders/               着色器
├─ tests/                 单元与集成检查
└─ tools/                 开发辅助工具
```

现有 `_ref_media/`、`参考图-加藤拓弎/` 和 `广告原图/` 是参考素材目录，本轮文档整理保持原位。`builds/`、`.godot/` 等本地产物不属于文档交付目录，忽略规则见根目录 `.gitignore`。

## 入口与边界

1. F5 正式入口为 `scenes/ui/start_menu.tscn`；`scenes/bootstrap/warehouse_main.tscn` 和 `scenes/bootstrap/main.tscn` 用于仓库、战斗调试。
2. `addons/` 保留上游插件代码；项目定制逻辑写在 `scripts/`，通过适配层使用插件。
3. 场景负责组合节点，算法和规则尽量写成可测试脚本或 Resource。
4. 预制战斗房间放在 `scenes/levels/rooms/`，抽取配置放在 `resources/rooms/`。
5. 组件基础数据、实例词条和存档结构分离，避免 UI 直接依赖 GLoot 内部实现。
6. 美术源稿与游戏使用的资源分开管理；素材搬迁需检查 `res://` 引用，不能仅按文件名整理。
7. `assets/fonts/` 内的非商用或许可未知字体不得用于公开发布版本，使用范围见[素材来源与许可](../legal/素材来源与许可.md)。

文档入口见[总导航](../README.md)，汇报资料见[汇报目录](../presentation/README.md)。
