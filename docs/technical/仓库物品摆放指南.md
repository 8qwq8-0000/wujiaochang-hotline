# 在 Godot 中摆放仓库物品

打开 `scenes/levels/base/warehouse.tscn`，切到顶部「2D」。如果 Godot 提示文件已在外部修改，选择重新加载磁盘版本。

在左侧场景树选择下面的父节点，按 W 切换移动工具，在画布中拖动；也可以在检查器的 Transform → Position 中输入坐标。按 ⌘S 保存。F6 运行当前仓库场景可检查效果，F5 从主菜单进入完整流程。

| 物件 | 选择的节点 |
| --- | --- |
| 装备储物箱 | Chest |
| 出击电梯 | Deploy |
| 盾反训练门 | ParryTraining |
| 试验场门 | Trial |
| BOSS 测试门 | BossTest |
| 工作台与合成师整组 | SynthesisNPC |
| 档案终端 | ArchiveTerminal |
| 零件架 | PartsRack |
| 两组货箱 | CratesLeft、CratesRight |
| 壁灯 | WarehouseArt/WallLamp1、WallLamp2、WallLamp3 |
| 玩家出生点 | Player |

物件使用 Godot 的节点分组，直接点击画布上的贴图通常会选中整组；场景树选择父节点最明确。移动父节点会带动子节点的 Art、交互 Shape、实体 Body/Shape 和名称标签。不要只移动 Art 子节点，否则只会改变贴图位置。不要缩放整个父节点来调整摆放，这也会缩放交互范围和碰撞。

工作台在 SynthesisNPC/Workbench 内，随合成师一起移动；需要单独调整两者的相对位置时，在场景树中选择 Workbench。场景使用独立透明 Sprite2D 和 AtlasTexture，原始 PNG 保持不变。

墙体和地板在编辑器中也可见，地面入口箭头和功能区域框会跟随对应服务节点。墙体当前为固定矩形房间边界，移动物件不会改变房间尺寸。靠墙时让物件的底部碰撞留在墙内，并保留通道；运行时可通过「调试 → 可见碰撞形状」检查。

验证：编辑器导入无解析错误；保存与重新实例化布局检查 59/59；仓库 58/58、合成师 40/40、盾反训练 50/50。检查使用独立临时存档，不改写正式玩家进度。退出仍存在项目既有的 ObjectDB/resource-in-use 诊断。

## 门前半法阵

四个门下新增 `DoorSigil` 子节点，移动门的父节点时一起移动。它在编辑器中显示静态预览，游戏中微弱呼吸发光，玩家进入原有交互范围时逐渐变亮，离开后恢复。`tint` 调整颜色，`radius` 调整半径，`facing` 选择朝下或朝左；位置是相对于门的坐标。法阵只显示在地板层，不提供额外碰撞。

法阵遮挡修订：DoorSigil 现在是 Polygon2D 裁切节点，子节点绘制完整圆形图案，朝墙的半边由门槛平面遮罩隐藏；没有半圆的直线封口。朝向、色彩、呼吸和靠近变亮仍沿用。

最新法阵版本：四个 DoorSigil 已改为 Sprite2D，使用原半法阵对称补齐的完整透明 PNG。直接调整 DoorSigil 的 Position 即可把整张法阵移入墙体；无需裁切或半圆遮罩。图案已有贴地透视，避免再次压扁。WallsArt 是独立的上层墙体绘制节点，负责自然遮挡法阵后半部。出击门法阵当前相对位置为 (22, 8)。
