# 主角盾反动画

右键沿用现有 GuardComponent 状态机，GuardVisual 用九帧透明图集替换原来的程序绘制圆弧。动画随瞄准方向旋转，朝上时在角色身后，侧面与朝下时在身前。

- 起手 0.06 秒：第 1–4 帧。
- 完美格挡窗口：固定第 5 帧，来自用户选定原图的等比缩小版本。
- 普通格挡 0.18 秒：第 6–7 帧；成功盾反时先保持第 5 帧 0.08 秒。
- 后摇 0.22 秒：第 8–9 帧，结束隐藏。暂停停止计时，死亡立即隐藏。

判定时间、角度、反弹与回热规则保持原实现。装备完美窗口加成和后摇倍率通过状态实际进度同步。完整画布在角色旁偏移 22 游戏像素，72 游戏像素见方；实际展开盾面约高 60 游戏像素。

素材：`assets/art/vfx/player/parry_shield.png`，312×312，3×3 网格，每帧 104×104；由 FrameRonin 技能的本地 process 命令最近邻缩放、切帧得到。高分辨率原件和制作记录保留于 `art_sources/ai_drafts/player_protagonist/parry_shield_peak5_v1/`。
