# 开阔车间与炸药桶布置

装卸车间沿用 C 的六空间、九门和上下环路。中央的大块设备改为约 39×33 px 的紧凑设备，左右各保留一处低掩体；通路上的家具缩小或移走，门宽由 64 px 提升到约 75.6–76 px。外侧出入口、区域尺寸和一层两区流程不变。每区仍为四近战、两远程。

## 炸药桶生成

`CombatRoom` 在区域创建时读取 `EnemySpawner.planned_positions()`，使用当次生效的出生计划（包括可选敌人的种子筛选）。炸药桶每区一只，生成后固定，不随敌人移动，延迟激活第二区域时也不会重新定位。

`EncounterPropPlacement` 在敌人周围及相邻敌人中点附近采样，优先选择爆炸能够覆盖最多敌人的落点，再在接近程度相近的候选位置中随机选择。有效爆炸范围按 92 px 保守评估，实际 `FuelPatch` 爆炸半径仍为 96 px。墙体、家具和关着的门遮挡爆炸计算，观察窗允许爆炸通视。

安全检查包括：

- 区域边界、墙体、家具与窗体保持至少 22 px 间距；
- 与敌人出生点至少相距 32 px，避免重叠；
- 避开门扇及门口的接近空间；
- 远离初始入口、最终出口和配电箱。

没有敌人时保留场景预设位置；若采样找不到合适的有效覆盖位置，也回退到预设位置。局种子、楼层编号和区域编号决定独立随机数源，不影响敌人刷出、房型和掉落抽取。相同局种子与区域可复现，换局或换楼层会变化。

## 验证

- `encounter_barrel_check.gd`：170 项检查，包括三敌人密集组优于两敌人组、种子复现及位置变化、B/C 各 16 个种子的落点导航可达与实际爆炸。32 次真实爆炸均命中至少两个敌人。
- `room_layouts_check.gd`：128 项，导航、道具点和跨区连接。
- `interlinked_rooms_check.gd`：48 项，角色实际通过所有门、窗口碰撞及射击。
- 两区推进 40 项、燃油/爆炸系统 19 项、48 项单元测试通过。

以上是游戏逻辑及占位构型调整；此前生成的完整像素美术效果图仍是美术目标，不是已实现的整套地图贴图。
