# 导电与配电箱

第一批实现 R1：导电状态 + 电击触发电弧。油污、燃烧和其他反应尚未实现。

## 试玩

Godot 打开 `scenes/debug/electric_reaction_sandbox.tscn`，按 F6。

- 左键导电枪分别命中三只标靶，Q 切换电击枪，再命中其中一个导电目标。
- 导电持续 6 秒，重复命中刷新；头顶显示倒计时。电弧依次寻找 96 像素内最近的导电目标，最多追加 3 个目标，每个受到 1 点电击并消耗导电。
- 配电箱附近按 E，随机获得攻速 ×1.25、散热 ×1.5 或格挡恢复时间 ×0.7，清空当前区域后结束。攻击箱子则破坏并释放半径 120 像素的电击，对玩家与敌人均造成 1 点伤害并施加导电；可触发已有导电。领取和破坏只能选一次。
- Tab 配装；R 重置试验场。三只标靶均有 8 点耐久，停止移动但使用实际敌人伤害链。

普通原型战斗房间也已放置配电箱。两把试验枪标记 debug_only，只由试验场发放，未加入普通掉落池。试验场不读写仓库装备存档。

## 边界

电弧走 HurtBox 和统一伤害结算，遵守阵营、无敌、墙体与 combat_rooms 容器范围。后续电弧禁止再次触发反应，避免递归。电击必须命中已有导电；同一次伤害新增的导电不会立即自行触发。

状态和表现随战斗暂停，跨场景不保留；房间增益不叠加，替换、源区域清场、死亡和源场景退出均还原倍率。原型层按现有 combat_rooms 容器划分空间，房间增益按实际 CombatRoom 归属清场。

## 实现与验证

`StatusComponent.handle_hit` → `ElectricReaction.discharge` → `HurtBox.receive_hit`。投射物从武器数据复制伤害类型和状态标签。`RoomBuffComponent` 管理临时倍率和生命周期，`PowerBox` 负责一次性结果及范围伤害。表现由 `StatusIndicator` 与 `VFXManager` 创建，使用 Godot 绘制；试验枪复用既有手枪场景和图标，未新增外部素材。

集成检查：`status_reaction_check.gd`、`power_box_check.gd`、`electric_sandbox_check.gd`，位于 `tests/integration/`，使用真实物理帧与项目场景，不需要修改玩家存档。图形验证使用 Godot Compatibility 渲染器；尚未验证 Windows 导出包。
