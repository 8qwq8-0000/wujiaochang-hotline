# 仓库储物箱

## 运行与交互

F5 运行项目先进入 `scenes/bootstrap/warehouse_main.tscn`，其继承原有 Main，仅覆盖 SceneFlow 的初始场景。`scenes/levels/base/warehouse.tscn` 是无敌人的安全房间，可 F6 单独检查箱子存取；完整出击需通过主入口。原 Main 继续供战斗调试和现有回归使用。

- WASD 移动，靠近中央箱子按 E 打开；打开时暂停世界并关闭玩家输入。
- 左侧列出主副武器、机动槽和普通背包；点击装备存入箱子。绑定初始装备禁用存入。
- 右侧列出箱内物品；点击取出到六格普通背包。满包拒绝操作，物品留在箱内。
- 箱子不限制件数，左右列表独立滚动。E / Esc / Tab 或关闭按钮退出。
- 要装备取出的组件，关闭箱子后按 Tab，在原配装界面操作。
- 右侧行动入口按 E 出击；清场后在出口选择撤离，再选择返回仓库。
- 新存档箱子为空，不赠送掉落装备。素材是现有角色与基础节点/脚本绘制占位。

## 数据与保存

`WarehouseStore` 是新增项目适配层，文件位于 Godot 的 `user://warehouse.json`，不修改第三方存档插件。顶层格式是 `version: 1`、`chest: Array` 和 `loadout: Dictionary`。

箱内存完整 GLoot 物品序列化，安全随身配置沿用 PlayerController 的状态快照。ID、品质等自定义属性保留。正常存取直接转移同一个 InventoryItem，不重新抽取装备。主副武器和机动槽存入时同步控制器，避免卸下后仍可攻击。

每次存取把箱子和随身配置一起写入临时文件，flush 后原子替换正式文件。写入失败回滚本次转移；无法读取、版本不兼容或结构异常时保留原存档并阻止写入。仓库内配装变化也自动保存，失败会提示。

出击前把随身快照传给当前行动，同时清空磁盘上的安全随身副本。箱内物品继续保留。行动加载失败时恢复安全随身配置。新行动刷新断路保险已使用标记、接管次数和首次武器拾取资格，不改变装备实例。撤离时先持久化带回配置，再显示成功；因此未回到仓库就关闭游戏，也可恢复战利品。

当前不保存进行中的行动；未撤离时关闭游戏或死亡，不会把随身物品自动退回仓库。箱内物品始终安全。黑匣物品保护、死亡结算页、存档迁移和多槽位不是本次实现内容。关卡之间仍沿用原项目的状态与灰盒模板。
