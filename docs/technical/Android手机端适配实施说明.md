# Android 手机端适配实施说明

## 架构与平台隔离

项目继续使用同一套 Godot 工程、场景、战斗逻辑和 `InputMap`，不复制“手机版工程”。平台差异只存在于输入表现与导出阶段：

- Windows 预设输出到 `build/windows/`，键盘、鼠标和手柄行为保持不变；触控层默认隐藏，可在设置中开启预览。
- Android 预设输出到 `build/android/`，包名为 `com.wujiaochang.hotline`，最低 API 28、目标 API 36，包含 ARMv7 与 ARM64。
- Android 在发现手柄输入后隐藏触控层；下一次真实触摸会恢复触控层。两种输入共用已有动作名，因此不会维护两份战斗代码。
- 两个平台使用各自系统的 `user://` 私有目录，不会互相覆盖存档；安装包、可执行文件和调试产物也在不同目录。

## 触控战斗

`MobileInput` 自动加载节点创建 Godot 4.7 内置 `VirtualJoystick` 与独立多点触控动作键。默认布局参考双摇杆动作游戏的右手操作习惯：左下移动，右下攻击、盾反、突进，右侧放置交互、换枪、背包和暂停。

- 攻击键使用右摇杆式点按/拖动状态机：触下时不立即误射，松手且未越过死区时自动重选当前最优目标并攻击一次；越过死区后按摇杆方向手动瞄准并按武器冷却连续攻击，回中或松手立即停止。
- 自动目标必须与玩家同房间、处于屏幕内且视线未遮挡；评分同时考虑距离、当前朝向与武器有效距离。非强制重选时，目标在死亡、离开屏幕、离开房间或被遮挡前保持稳定。
- 盾反键仍可拖动指定手动防御方向；松手后恢复自动选择。没有合法目标时保留玩家最后朝向。
- 环境物不参与自动瞄准，仍需拖动手动瞄准。
- 突进继续复用既有规则：有移动输入时按移动方向，没有移动输入时按朝向。
- 自动目标环可关闭。触觉反馈默认开启，仅用于受伤和完美盾反等关键事件。

## 按键编辑

设置页新增触控预览、左手模式、触觉反馈、目标指示、布局编辑和重播教学。布局编辑支持：

- 拖动每个控件，并限制在系统安全区域内；
- 分别调整选中控件的缩放和透明度；
- 一键恢复右手或镜像左手默认布局；
- 右手、左手布局分别保存在 `PlayerConfig`，不会改变动作绑定或删除必要按键。

## 背包触控丢弃

背包格在触屏上按住 0.36 秒后开始原生拖放。底部红色区域是“丢到地上”目标：成功放下后复用现有 `discard_backpack_item()` 事务，先持久化所有权变化，再在玩家脚边生成同一个 `InventoryItem` 实例，随后关闭背包。失败会恢复原实例与顺序，不会销毁或复制物品。桌面右键丢弃与鼠标拖放继续保留。

## Android 生命周期与边到边

- 固定为传感器横屏，允许左右两个横屏方向；触控布局使用 `DisplayServer.get_display_safe_area()` 避开刘海与挖孔。
- Android 系统返回键不会直接退出：教学中关闭教学，编辑中保存并退出编辑，游戏中打开暂停，弹窗/背包中沿用原有返回动作。
- 切到后台、锁屏或失去焦点时暂停并临时静音；恢复后停留在暂停菜单，且恢复用户原来的静音状态。
- 若系统杀死进程，现有仓库持久化存档仍作为安全恢复点，不保存战斗中的逐帧状态。
- 导出预设禁用网络、存储、媒体、相机、麦克风、位置和通知权限，仅开启震动权限。

## 验证

在 Godot 4.7.2 Compatibility/Headless 下完成：

- 95 项现有单元测试全部通过；
- `mobile_controls_check.gd`：内置移动摇杆、攻击点按/拖动摇杆、最优目标重选、手动连续攻击、地面拾取显隐与实际触控拾取、左右手镜像、布局编辑、系统返回键，零失败；
- `settings_menu_check.gd`：设置页与暂停所有权，零失败；
- `inventory_pause_check.gd`：背包暂停/恢复与原桌面操作，零失败；
