# 敌人视野与声音警戒

分支：`feature/enemy-alert`，基于 `integration/week1` 的 `e2a697f`。本次仅接入已有战斗原型，没有纳入 last1118 的关卡或素材。

## 行为

- 待机敌人保留初始朝向，不再仅因距离接近就追击。玩家进入视野角度、距离且没有墙体遮挡时触发警戒。
- 存活敌人受到带有有效来源的伤害时，被惊动并记录攻击来源位置。
- 手枪、散射器成功攻击时发送一次游戏逻辑声音事件；冷却或过热拒绝攻击时不发送。警棍默认安静。
- 声音同时受武器半径和敌人听力范围限制，墙体遮挡会缩短有效传播距离。背包暂停时不处理声音。
- 新被惊动的敌人只唤醒同一战斗场景内、距离与视线满足条件的附近同伴；接收同伴警报不会再次广播，避免连锁唤醒整层。
- 失去视线后只向最后已知位置移动，停止更新隐藏玩家的位置。到达后停留，记忆计时结束则回到待机；重新看到、听到或受到攻击会刷新记忆。
- 玩家死亡后敌人停止追击。警戒时头顶显示黄色点，朝向用短线表示。

近战和远程资源已开启短距离巡逻，重装仍原地待机警戒。未新增尸体发现或复杂潜行机制。

## 参数

参数位于 EnemyProfile，各敌人资源可单独覆盖。以下为原型默认值，仍需人工试玩调节。

| 参数 | 默认值 |
|---|---:|
| 视野距离 awareness_range | 240 px |
| 视野夹角 vision_angle_degrees | 120° |
| 听力范围 hearing_range | 240 px |
| 隔墙声音距离乘数 blocked_sound_multiplier | 0.4 |
| 同伴警报范围 ally_alert_range | 96 px |
| 目标记忆 alert_memory_seconds | 3 s |
| 巡逻距离 patrol_distance | 32 px |
| 巡逻速度 patrol_speed_ratio | 正常移动速度 × 0.45 |
| 端点停留 patrol_pause_seconds | 1.2 s |
| 被阻挡超时 patrol_blocked_timeout | 1 s |

敌人场景可设置 `initial_facing`；默认朝左。制式手枪声音半径 240 px，散射器 300 px；敌人仍以自己的听力范围作为上限。

## 接口和边界

`CombatEvents.publish_noise(source, origin, radius)` 是逻辑声音事件，不代表增加了音频素材。枪击已接入实际 WeaponController；爆炸与撞门尚未实现，应在对应功能完成后调用这一接口。使用有效且仍在场景树中的来源节点，origin 是事件发生位置，radius 是传播距离。

敌人每次从未警戒切换为警戒、且本次警报允许向同伴传播时，会发布一次 `CombatEvents.enemy_alerted`。`AudioCueManager` 将其映射为 `reinforcement_approach.wav`，表示敌方增援正在接近，并以 3 秒冷却抑制多个敌人同时发现玩家造成的声音叠加。当前尚未实现真正的增援生成；该事件是后续增援生成器与声音提示共用的接入点，不是玩家步行音。

声音与同伴警报限于同一个 `combat_rooms` 祖先节点。当前该节点是战斗楼层；未来跨区域设计应保留楼层范围，并进一步加入区域传播规则。声音不会影响另一个已载入的独立战斗场景。

没有修改第三方插件、导入新素材或新增存档格式。本功能由 Codex 辅助实现。

## 验证

`tests/integration/enemy_alert_check.gd` 覆盖朝向、距离、墙体视线、隔墙听力、声音半径、受击、最后已知位置、记忆失效、暂停、同伴警报距离/遮挡/禁止递归、场景隔离、实际枪击与冷却失败、安静近战。

原有绕障碍检查改为明确提供一次已发现的玩家位置，验证已警戒敌人的导航；没有把“隔墙也自动知道玩家在哪”保留为要求。

16 项单元检查、10 套集成检查通过，Godot 编辑器实际启动成功，无新增解析或运行错误。仍有此前的主场景退出资源释放警告；Windows 与人工手感验收未完成。

## 试玩

F5 运行主场景：靠近敌人时观察朝向短线，从背后靠近或隔掩体站立不会只因距离触发追击；进入视野后观察黄色警戒点。拾取手枪后，在敌人背后开枪可用声音唤醒附近敌人。打开背包暂停时，敌人及警戒记忆计时停止。R 重开恢复待机状态。

## 短距离巡逻补充

`EnemyProfile.patrol_enabled` 默认关闭；当前近战、远程原型资源启用，重装原型不启用。普通巡逻按出生点最近墙体的方向，在出生点两侧沿固定直线往返；横墙旁左右走，竖墙旁上下走。端点停留后换方向。巡逻面对移动方向，因此玩家从不同角度接近会影响发现时机。

发现玩家、听到声音或受击后立即进入警戒；记忆结束后经导航返回原出生区域，再继续巡逻。巡逻锚点不随追击位置漂移。没有可行路线时停留并重试，不能通过墙体或用瞬移返回。普通巡逻不使用导航绕障碍；碰到障碍后停留并折返。只有追击与从追击位置返回出生点使用导航，返回状态单独标记为 RETURN_TO_PATROL。

暂停会停止巡逻移动及停留计时；死亡后不再恢复巡逻。没有玩家的独立敌人测试场景也支持巡逻。

新增 `enemy_patrol_check.gd`：验证两侧移动、出生范围、端点停留、暂停、声音中断、丢失目标后返航和恢复、锚点不漂移、墙体阻挡与端点跳过、关闭巡逻和死亡停止。另回归视野声音、绕障碍掉落、背包暂停、三种重开和三轮完整流程，均通过。

巡逻方向参数 `patrol_axis` 默认 AUTO_WALL：首次巡逻时从出生点向四个方向探测最近的世界层墙体／掩体，根据命中面的切线选择水平或垂直轴。未找到墙体时采用水平轴。也可显式设置 HORIZONTAL 或 VERTICAL。巡逻不再依赖敌人的初始朝向，初始朝向仍决定首次视野方向。检查补充覆盖横墙/竖墙自动选轴和不偏离固定巡逻线。

## 正式生成器与显示修正

实际运行发现 EnemySpawner 原先先 add_child、再设置 global_position，导致 EnemyController._ready 提前将巡逻锚点记为 (0,0)。现改为先把 Marker 世界坐标转换成生成父节点的局部坐标，再添加敌人；带偏移的房间也保持正确位置。

`spawned_patrol_check.gd` 直接运行正式 Main 与 EnemySpawner，检查出生锚点、墙体平行轨迹、原地重装和带偏移房间。正式生成取样：近战 x=344、y约64.4～119.6；远程 x=512、y约150.5～205.5；正常巡逻没有返回地图原点。另回归巡逻、警戒、掉落、重开、跨房间和连续三轮流程。

远程敌人的旧固定向右枪管线已移除，所有敌人仅保留一条随 facing 转动的方向线，避免出现重复的横线与竖线。
