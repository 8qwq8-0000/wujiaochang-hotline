# 轮式冲撞

> **已废止（v1.5）**：本文保留旧轮式组件的实现记录，不再是现行目标规格。新规则见[固有突进与义体迁移实施说明](固有突进与义体迁移实施说明.md)。当前代码尚未完成迁移。

轮式推进组件改为冲撞破阵用途。普通 WASD 全向移动取消方向插值和侧滑：最高速度 150 px/s，加速 2200 px/s²，制动及反向减速 3000 px/s²。起步不受鼠标朝向影响。

Space 优先沿当前 WASD 输入方向冲撞；无输入则沿瞄准方向。冲撞速度 420 px/s、持续 0.20 s、平地距离约 84 px，制式/改良/原型冷却分别为 1.2/1.0/0.8 s。期间方向固定，结束恢复普通移动速度范围，撞墙提前结束且保留冷却。泥地等地形仍影响速度。前 0.15 s 提供无敌帧，撞墙、卸装或重置提前结束冲撞时立即取消冲撞无敌，不影响受击或保险等其他无敌来源；不新增穿墙或越障能力，保留武器和格挡操作，支持接警棍。

使用实际位移路径的胶囊查询检测敌人 HurtBox，沿用 DamagePacket/HurtBox 伤害链；每次冲撞对每个敌人按制式/改良/原型分别造成 2/3/4 点伤害。成功造成伤害且目标存活时调用敌人的 apply_stagger(0.65)，取消普通攻击前摇。沿用重型敌人进入自爆状态后不接受硬直的规则。墙体视线查询防止接触半径隔墙伤敌。没有把“stagger”状态标签用于新逻辑，避免与既有状态持续时间混淆。

冲撞半径 14 px；伤害、硬直、半径和无敌时长集中配置在 WheelMobilityMode。机动速度词条继续作用于普通最高移速，不额外改变冲撞伤害。HUD 显示“冲撞 SPACE”或剩余冷却。

背包存档失败回滚同时恢复冲撞方向与本次命中集合，避免回滚后停滞或重复伤害。既有存档继续引用 wheel 物品和原资源路径，无需删档。

验证：wheel_ram_check.gd 共 34 项，使用真实物理帧覆盖起步、反向、停止、方向锁定、伤害与去重、打断前摇、冷却、卸装、无敌自然到期、撞墙、隔墙不伤敌、5 Hz 物理步长下的路径扫描及接警棍实际伤害。另执行单元测试、品质词条、背包拖拽与残影回归。

无敌帧专项验证：通过真实 HurtBox 伤害入口检查近战、射击、爆炸及电击免伤，阻止附带状态、击退及装甲消耗；检查最后 0.05 s 恢复受伤、撞墙和卸装提前取消，以及其他来源无敌继续有效。

## 基础节奏调整

玩家步行 155 → 125 px/s，轮式普通移动 150 px/s，装上后相对步行基础提升 20%（另计词条）；四足 185 → 150、飞行 215 → 175 px/s。三种敌人近战/狙击/重型从 125/72/58 降至 100/58/46 px/s，巡逻与侧移继续使用各自速度比例。

普通武器攻击间隔：警棍 0.38 → 0.48 s，手枪 0.22 → 0.28 s，散射 0.72 → 0.90 s；兼容警棍资源、试验枪、武器模板与默认值同步调整。敌人攻击冷却 0.65/1.15/1.45 → 0.82/1.44/1.82 s。移动约慢 20%，攻击间隔延长约 25%，即攻速约慢 20%。攻击前摇、子弹速度、近战有效帧与冲撞参数保持原值，以保留输入响应和冲撞的爆发差异。现有机动词条继续在新移速基础上加成，无需删档。

## 机动升级重心

各品质轮式基础移速均为 150 px/s，品质主要增强冲撞伤害与缩短冷却。参数集中于 ComponentRolls.WHEEL_RAM_DAMAGE 和 WHEEL_RAM_COOLDOWNS，经 mobility_mode() 克隆资源后应用，描述与合成预览引用同一参数。旧存档按原品质自动使用新数值，不重掷词条。冲撞距离和无敌窗保持 84 px / 0.15 s。
