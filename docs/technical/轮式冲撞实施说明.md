# 轮式冲撞

轮式推进组件改为冲撞破阵用途。普通 WASD 全向移动取消方向插值和侧滑：最高速度 245 px/s，加速 2200 px/s²，制动及反向减速 3000 px/s²。起步不受鼠标朝向影响。

Space 优先沿当前 WASD 输入方向冲撞；无输入则沿瞄准方向。冲撞速度 420 px/s、持续 0.20 s、平地距离约 84 px，冷却 1.4 s。期间方向固定，结束恢复普通移动速度范围，撞墙提前结束且保留冷却。泥地等地形仍影响速度。不新增无敌、穿墙或越障能力，保留武器和格挡操作，支持接警棍。

使用实际位移路径的胶囊查询检测敌人 HurtBox，沿用 DamagePacket/HurtBox 伤害链；每次冲撞对每个敌人最多造成 1 点伤害。成功造成伤害且目标存活时调用敌人的 apply_stagger(0.65)，取消普通攻击前摇。沿用重型敌人进入自爆状态后不接受硬直的规则。墙体视线查询防止接触半径隔墙伤敌。没有把“stagger”状态标签用于新逻辑，避免与既有状态持续时间混淆。

冲撞半径 14 px；伤害、硬直、半径集中配置在 WheelMobilityMode。机动速度词条继续作用于普通最高移速，不额外改变冲撞伤害。HUD 显示“冲撞 SPACE”或剩余冷却。

背包存档失败回滚同时恢复冲撞方向与本次命中集合，避免回滚后停滞或重复伤害。既有存档继续引用 wheel 物品和原资源路径，无需删档。

验证：wheel_ram_check.gd 共 34 项，使用真实物理帧覆盖起步、反向、停止、方向锁定、伤害与去重、打断前摇、冷却、卸装、无额外无敌、撞墙、隔墙不伤敌、5 Hz 物理步长下的路径扫描及接警棍实际伤害。另执行单元测试、品质词条、背包拖拽与残影回归。
