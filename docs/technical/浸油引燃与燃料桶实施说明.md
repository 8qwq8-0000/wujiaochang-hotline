# 炸弹箱与短暂危险区域

原 FuelBarrel 场景现按炸弹箱使用：警棍、现有枪械和火焰/热能的有效攻击都能直接引爆；不再要求先漏油、再使用其他来源点燃。没有新增武器。

## 试玩

F5 进入仓库，从“试验场入口”按 E 进入。用初始警棍近战攻击炸弹箱，或从左侧测试箱取现有手枪、关闭后 Tab 配装，远距离射击。一次爆炸对玩家和敌人均造成 1 点环境火焰伤害，半径 96 像素；近身打箱也会伤及自己。随后留下半径 64 像素的火区 4 秒，每秒造成 1 点环境伤害，离开火区即可避免继续受地面伤害。

R 重置箱子和火区，返回仓库不会带出测试物品或伤害。自动门和配电箱也在同一试验场；右上角改为“测试：电击标靶”，爆炸无需测试按钮。

## 边界与状态支持

- 在伤害回调前锁定一次性破坏；重复近战、散射弹丸与后续攻击都不能重复引爆。花费后的箱子不再吸收弹丸。
- 爆炸和火区受墙体、距离与 EnvironmentArea 实际区域隔离，玩家和敌人按同一规则结算；不破坏墙体，不制作燃料桶之间的自动连爆。
- 沿用原油污反应接口：独立油区存在 8 秒，每 0.2 秒刷新 6 秒浸油；fire 或现有 thermal 伤害可引燃旧浸油，燃烧 3 秒、每秒 1 点、重复刷新不叠加。正式炸弹箱不再产生这个油区，不新增油枪或火焰枪。
- 爆炸、火区和状态走 HurtBox/Health，遵守无敌、保险和暂停。保险清除燃烧后不留计时伤害。火区与已有角色燃烧为两种来源，站在火区且已燃烧时可分别受伤。

## 实现与验证

FuelBarrel 接收攻击、锁定结果并延后创建已点燃的 FuelPatch；后者只结算一次爆炸，再处理短暂火区。EnvironmentArea 查询实际区域内存活且无遮挡的角色。表现使用 Godot 基础绘制和既有 VFXManager，无新增外部素材。

fuel_environment_check 验证双阵营伤害、墙体/范围/区域隔离、重复攻击、现有手枪真实弹丸、火区过期与油污接口；fuel_sandbox_check 验证实际警棍引爆和玩家自伤；oil_status_check 验证实际燃烧计时、暂停、刷新及保险。图形检查使用 macOS Godot Compatibility，未验证 Windows 导出包。

## 测试储物箱

试验场左侧放置测试箱，E 打开/关闭，Esc 或 Tab 也可关箱。库存从正式道具原型动态生成，排除 debug_only 与绑定道具；绑定初始警棍开局已随身携带。当前供应破门警棍、制式手枪、散射武装、轮式推进组件、断路保险核心。成功取出后补充一件新实例，使用独立实例编号；存回的装备保留自身属性。仍限制背包六格和保险核心唯一，重复取用的失败操作不消耗库存。

复用仓库面板，通过可配置标题与提示避免显示“自动保存”。数据只存在试验场节点中，不调用 WarehouseStore.commit；R 重建默认库存和装备，返回仓库恢复正式存档。试验场玩家单独开启 allow_trial_equipment_changes，存活标靶不会阻止 Tab 拖动配装；正式行动仍按原规则限制换装。

`trial_chest_check.gd` 验证真实 E 和鼠标取用、补货实例、满包/绑定/保险限制、带标靶配装、关箱恢复、R 重置和正式战斗限制。`trial_entry_check.gd` 从测试箱实际取物后返回仓库，检查正式存档与装备未受影响。

测试箱右侧按原型清单固定显示，每种道具只占一行；补货与存回的重复实例不改变行位置，实际实例仍保留在箱内。普通仓库保持逐件展示。
