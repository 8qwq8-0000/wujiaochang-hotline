# 浸油引燃与燃料桶

第二批实现 R2，沿用第一批的 StatusComponent、HurtBox 和伤害标签流程。过热热震尚未实现。

## 试玩

F5 进入仓库，走到上方偏右“试验场入口”按 E，或打开 `scenes/debug/fuel_reaction_sandbox.tscn` 按 F6 独立运行。WASD 靠近燃料桶，左键用初始警棍打破，走进油区观察浸油倒计时。点右上角“测试：点燃油区”按钮观察爆炸和火区。Tab 打开背包，R 重置。

本批只新增燃料桶及其环境反应，不发放新武器、不写入仓库存档。点燃按钮仅用于独立试验场验证；正式攻击来源留待武器开发阶段接入。试验场同时提供配电箱，用 E 或攻击验证第一批环境交互。右下角返回按钮可在死亡后使用，恢复仓库存档；R 只重置当前试验场。进入前保存正式装备，试玩期间不写存档，清场掉落、换装、死亡都不会带回正式流程。普通原型战斗房间也已放入燃料桶。

## 规则

- 浸油持续 6 秒，刷新时长、不叠层；单独浸油不造成额外伤害。
- 火焰成功命中已有浸油的存活目标后，消耗浸油，燃烧 3 秒，每秒 1 点伤害，共 3 次。原始命中伤害照常结算。一次命中新施加的浸油不在当次自行引燃。
- 再次浸油后引燃只刷新同一条燃烧，不增加伤害流。燃烧继承触发攻击的阵营，禁止反应递归，不可格挡或反射，遵守 HurtBox 无敌。被格挡、阵营免伤或无敌拒绝的火焰命中不会引燃。
- 燃料桶一次性破坏；油区半径 64 像素、存在 8 秒，每 0.2 秒向范围内存活角色刷新浸油。普通子弹穿过油区，火焰子弹可点燃。
- 点燃产生一次半径 96 像素、1 点环境火焰爆炸，留下半径 64 像素的火区 4 秒，每秒造成 1 点环境火焰伤害。爆炸与火区均伤害玩家和敌人，且能引燃已有浸油。火区伤害与角色自身燃烧是两种来源，站在火区中会同时受到两者伤害。
- 范围作用受墙体、距离与 combat_rooms 容器隔离。墙体阻断爆炸、油区施加与火区伤害；不制作破墙和燃料桶之间的自动连爆。
- 状态、区域寿命和伤害随战斗暂停。断路保险在致命燃烧时可清除状态，清除后没有残留计时伤害；跨场景不保存。

## 实现与验证

`StatusComponent.handle_hit/ignite` 负责反应和同一条燃烧计时；`FuelBarrel` 预先锁定一次性破坏，延后创建 `FuelPatch`，后者处理油区、引爆和短暂火区。燃烧伤害通过现有 HurtBox，角色保险在伤害回调内清状态时，计时循环不会写回旧状态。表现使用 Godot 基础绘制和既有 VFXManager，无新增外部素材。

新增独立检查：`oil_status_check.gd`、`fuel_environment_check.gd`、`fuel_sandbox_check.gd`，位于 `tests/integration/`。验证真实物理帧、普通近战打桶、测试按钮鼠标点击、R 输入、状态刷新、三次伤害、暂停、保险、墙体/范围/房间隔离、重复引爆和区域回收。图形检查使用 macOS Godot Compatibility 渲染器，未验证 Windows 导出包。
