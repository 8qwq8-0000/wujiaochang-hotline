# 背包丢弃

打开背包，右键背包物品，选择“丢到地上”。只有普通背包内、仍归当前玩家所有的物品可操作；死亡或伤害结算期间拒绝。装备槽和黑匣内容须先取回背包，未清场时仍遵守原有换装限制；丢弃普通背包物品本身不要求清场。

物品移动到玩家脚边的 ComponentPickup，保留同一 InventoryItem 实例、ID、品质、词条和装甲剩余冷却。关闭背包后靠近按 E 拾回，满包时维持地面状态；不会自动重新拾取。地面丢弃物不写入仓库存档，离开或重开当前场景未拾回则丢失。试验场遵守原隔离规则。

先移出背包并保存当前安全快照，成功后才生成地面物品；保存失败恢复同一实例及原索引，不生成掉落。重复/过期/异物引用不允许重复丢弃。未改动“拖出窗口取消”的原行为，使用明确的右键动作。

mobility_and_discard_check.gd 覆盖品质数值、描述/合成预览、真实右键菜单、同实例丢弃与拾取、装甲冷却保留、过期引用及保存失败。另回归原生拖拽、冲撞、无敌和完整出击。
