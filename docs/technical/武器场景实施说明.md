# 武器场景实施说明

> 对齐策划案 v1.3 与《素材制作基线》；范围为脚本、场景和开发占位，不新增正式美术或音频。

## 1. 职责边界

武器场景只负责手持表现、枪口与特效挂点、后坐/残影，以及向统一音频层发送提示事件。权威战斗状态仍由现有组件维护：

- `WeaponController`：攻击冷却、近战判定、弹丸生成和武器切换；
- `HeatComponent`：主副武器共享热量与过热；
- `WeaponComponentData`：武器数值和对应 `view_scene`；
- `WeaponMount`：只实例化当前选中的一个 `WeaponView`；
- `WeaponView`：纯表现，不修改伤害、热量或冷却。

切换武器会立即销毁旧表现并取消其残余动画，但不会重置共享热量或攻击冷却。

## 2. 场景契约

每个武器场景的根节点必须挂载 `WeaponView`，并保留以下节点：

```text
WeaponView
├─ BodyRoot
│  └─ BodySprite
├─ MuzzleSocket
│  └─ MuzzleFlash
└─ EffectSocket
   └─ MeleeTrail
```

- `BodyRoot`：后坐和装备出现动画的局部根节点；
- `MuzzleSocket`：枪械弹丸与枪口提示事件的真实起点；
- `EffectSocket`：近战残影等局部效果挂点；
- 缺少 `view_scene` 时，`WeaponMount` 使用 `scenes/weapons/weapon_view.tscn` 并输出一次警告；
- 枪口越过墙面时，`WeaponController.clamp_projectile_origin()` 会把弹丸起点收回到墙前；
- 弹丸从安全枪口位置指向鼠标世界坐标，鼠标过近时退回当前角色朝向。

## 3. 当前武器场景

| 武器数据 | 表现场景 | 攻击类型 |
|---|---|---|
| `initial_baton.tres` | `initial_baton.tscn` | 绑定初始近战 |
| `baton.tres` | `baton.tscn` | 掉落近战 |
| `service_pistol.tres` | `service_pistol.tscn` | 单发弹丸 |
| `scattergun.tres` | `scattergun.tscn` | 散射弹丸 |

四个场景暂时共用 `placeholder_weapon_spear.png`，仅通过颜色和反馈幅度区分。占位图遵循玩家序列帧的最近邻过滤、整数坐标与左右镜像规则；它不参与碰撞或伤害判定。

## 4. 新增普通武器

1. 复制 `resources/weapons/templates/weapon_template.tres`；
2. 复制 `scenes/weapons/templates/weapon_view_template.tscn`；
3. 修改数据的唯一 `id`、名称、攻击参数和 `view_scene`；
4. 调整场景中的像素主体、`MuzzleSocket` 与反馈参数；
5. 在 `resources/items/components.json` 显式登记物品元数据；
6. 把正式素材来源和许可证写入 `docs/legal/素材来源与许可.md`；
7. 运行单元检查和 `tests/integration/weapon_scene_check.gd`。

普通近战、单发和散射武器不需要修改控制器。只有新增真正不同的攻击机制时，才扩展 `AttackKind` 或增加独立攻击策略。模板不会自动进入正式掉落池。

## 5. 音效接口

`WeaponView` 在实际表现播放时发出 `swing` 或 `fire` 提示，经 `WeaponMount` 发布到 `CombatEvents.weapon_cue_requested`。`AudioCueManager.weapon_cues` 使用 `<weapon_id>:<cue>` 作为键，例如：

```text
service_pistol:fire
baton:swing
```

未配置音频时静默运行。配置后由 `AudioCueManager` 创建带空间位置的 `AudioStreamPlayer2D`；武器场景不直接绑定临时音频文件。

## 6. 验证

- `tests/test_weapon_scenes.gd`：四件运行时武器的场景契约、最近邻过滤，以及模板不进入掉落目录；
- `tests/integration/weapon_scene_check.gd`：初始挂载、主副切换、单实例、枪口生成、墙面收回、表现与战斗状态隔离、缺失场景回退；
- 原有 `weapon_switch_check.gd` 和 `shooting_input_check.gd` 继续覆盖快捷切换与四方向弹丸行为。
