# 撤离结算

清理本层所有战斗区域后，走入已启用的出口，弹出小窗口选择撤离或继续下一层。选择时不暂停世界，玩家可以移动；走出出口范围自动关闭，再次走入会重新显示，Esc 也可关闭。撤离成功后进入暂停的结算页，不能返回已结束的战斗。

- 撤离复制主武器、副武器、机动装备和背包各物品的完整序列化数据，按实例去重；地上未拾取的掉落不会带出。绑定初始装备列入携带清单。
- `RunManager.extraction_result` 保存本局种子、层数、玩家完整状态和带出物品清单；重复结算被拒绝，死亡或未清场时不能结算。
- 继续下一层保留耐久、装备、背包及现有跨房间状态，并增加层数。当前复用灰盒战斗模板，不代表四层内容已经完成。
- 结算页可开始新一局，清空上一局状态，恢复初始装备和空背包。

当前只有运行内结算数据，没有写入永久仓库或存档。关闭游戏会丢失这次结果；界面明确提示此限制。仓库存储、基地配装、死亡损失与黑匣保护将分别接入，不能把本功能视为完整搜打撤闭环。

验证：`godot --headless --path . --script res://tests/integration/extraction_check.gd`。覆盖真实出口、未清场和死亡拒绝、暂停恢复、继续层状态保留、装备与背包结算、重复提交、新一局重置。
