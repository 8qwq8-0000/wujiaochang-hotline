# 撤离结算

清理本层所有战斗区域后，走入已启用的出口，弹出小窗口选择撤离或继续下一层。选择时不暂停世界，玩家可以移动；走出出口范围自动关闭，再次走入会重新显示，Esc 也可关闭。撤离成功后进入暂停的结算页，不能返回已结束的战斗。

- 撤离复制主武器、副武器、机动装备、黑匣和背包各物品的完整序列化数据，按实例去重；地上未拾取的掉落不会带出。绑定初始装备列入携带清单。
- `RunManager.extraction_result` 保存本局种子、层数、玩家完整状态和带出物品清单；重复结算被拒绝，死亡或未清场时不能结算。
- 继续下一层保留耐久、装备、背包及现有跨房间状态，并增加层数。当前复用灰盒战斗模板，不代表四层内容已经完成。
- 撤离成功前把完整随身配置提交到 `WarehouseStore`；保存失败时不结束行动，可重试。结算页选择“返回仓库”，整理箱子和配装后再次出击。

箱内与安全随身装备现已写入 `user://warehouse.json`，撤离成功后即使未点击返回仓库，关闭游戏也不会丢失带回装备。出击时移交随身物品的归属，普通装备不留安全副本，仅保留黑匣与初始绑定装备的恢复配置。死亡结算保存受保护物品后可返回仓库，失败时提供重试；完整关卡中途续玩尚未实现。详情见 `仓库储物箱实施说明.md`。

验证：`godot --headless --path . --script res://tests/integration/extraction_check.gd`。覆盖真实出口、未清场和死亡拒绝、暂停恢复、继续层状态保留、装备与背包结算、重复提交、回仓与再次出击。
