# 自动门与冲刺撞门

2026-10-22 更新：有效子弹命中关闭的自动门时，一发即可打碎门板，产生现有碎片和警戒声，并解除阻挡。命中的那发子弹会消耗，后续子弹可以穿过门口；射击破门不会触发冲刺撞门的击倒。支持双向射击及旋转后的门，重复命中不重复生成碎片。下文保留早期设计记录，以此更新为准。

门使用 AutomaticDoor、接触 Area2D 和 StaticBody2D 面板，不加入耐久或破坏动画。玩家或敌人接触会自动开启，打开后保持开启，重新加载区域恢复关闭。关闭的门阻挡角色、弹丸和范围作用的射线；打开时移除阻挡形状。

玩家必须处于固有突进有效期并朝门移动，才计为冲刺撞门；单纯走得快或被击退不算。固有突进不依赖装备：有 WASD 输入时沿输入方向、无输入时沿鼠标瞄准方向按 Space 触发。

撞门使门后前方 60 像素、左右各 38 像素范围内的存活敌人击倒 0.8 秒，打断攻击并轻微击退，不附加伤害。门前、侧方、远处、墙后和其他区域敌人不会被击倒。支持从两侧撞开，开着的门不再重复击倒；暂停停止恢复计时。头顶显示击倒倒计时。撞门发出警戒声音。

自动门已经放入正式普通地图模板；不同地图的门数量和朝向由对应布局资源定义。通道封锁线由 `CombatPassage` 单独管理，不属于自动门。

`automatic_door_check.gd` 通过真实移动、固有突进、碰撞帧和弹丸验证开门、射击破门与后续放行、双向冲刺、普通敌人接触、击倒范围/墙体/区域隔离、暂停、恢复及防重复。
