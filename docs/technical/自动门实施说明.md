# 自动门与冲刺撞门

门使用 AutomaticDoor、接触 Area2D 和 StaticBody2D 面板，不加入耐久或破坏动画。玩家或敌人接触会自动开启，打开后保持开启，重新加载区域恢复关闭。关闭的门阻挡角色、弹丸和范围作用的射线；打开时移除阻挡形状。

玩家必须正在机动技能有效期内且朝门移动，才计为冲刺撞门；单纯走得快或被击退不算。轮式推进组件可从试验场测试箱取出，关闭箱子后 Tab 拖入机动槽，鼠标朝向门、按空格冲刺。步行没有冲刺能力。

撞门使门后前方 60 像素、左右各 38 像素范围内的存活敌人击倒 0.8 秒，打断攻击并轻微击退，不附加伤害。门前、侧方、远处、墙后和其他区域敌人不会被击倒。支持从两侧撞开，开着的门不再重复击倒；暂停停止恢复计时。头顶显示击倒倒计时。撞门发出警戒声音。

门目前只放在环境试验场，正式战斗关卡暂不放置。试验标靶通过 stationary_test_target 保持原地，但仍运行真实的受击和状态计时，以便验证击倒后的恢复；正式敌人默认不启用该模式。

automatic_door_check 通过真实移动、机动冲量、碰撞帧和子弹验证开门、挡弹/放行、双向冲刺、普通敌人接触、击倒范围/墙体/区域隔离、暂停、恢复及防重复；fuel_sandbox_check 额外验证试验标靶的实际恢复。
