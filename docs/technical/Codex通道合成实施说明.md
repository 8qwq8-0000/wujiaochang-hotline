# 第二层后的 Codex 整备通道

第二层清场后选择“继续下一层”，进入独立检修通道。此时仍处于第二层与第三层之间，不发放额外人格授权或接管补给。第二层选择撤离仍使用原结算路径；第一层继续、第三层进入楼顶 Boss 的路径保留。

通道复用仓库 `SynthesisNPC` 的现有角色贴图、裁切区域、显示尺寸和工作台，以及仓库墙、地板、灯、箱子、终端和电梯素材。仓库原节点、名字和功能未修改；通道中的角色显示名为 Codex。不使用重新生成的角色素材。工作台、终端与箱子贴北墙摆放；出口贴东墙。出口复用仓库行动入口的完整地面光环及接近增亮脚本，地板位于光环下层，墙体和门框遮挡背面的光环。

靠近 Codex 按 E，完成四段对话后自动打开合成台。Esc 可中止并稍后继续对话；完成后再次交互直接打开合成台。对话前出口尚未接通；对话后允许合成零次或多次，再到右侧出口按 E 进入第三层。

合成台复用 `synthesis_panel.gd`，标题与空列表提示可配置。只使用本次行动的装备和背包，不访问永久仓库。武器、防御沿用同槽同品质规则；义体模块取并集，最多四种，重复效果不叠加，不可拆分。两件材料消耗，成品返回主体原位置；装备槽主体合成后立即更新实际战斗效果，满背包仍可消耗背包材料升级。校验来源、兼容性、重复请求和对话解锁；放置失败时恢复合成前快照。

进入通道和第三层时传递同一行动的生命、装备实例、人格和天赋，并携带热量及过热状态；行走时正常散热，对话及工坊暂停。合成更新局内 RunManager 快照，不把义体写入永久仓库存档。第三层仍正常打开该层的人格整备界面。
