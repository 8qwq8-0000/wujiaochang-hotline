# 黑匣与死亡保护

## 玩家操作

Tab 打开背包。黑匣是独立的一格，不占六格普通背包；初始存放一枚断路保险核心。

- 在背包下拉菜单选择“把背包物品放入黑匣 / 交换”，然后点击一件背包物品。
- 黑匣已占用时与选中物品原子交换，满包也可交换；单独取出需要背包空格。
- 点击黑匣按钮把其内容取回普通背包。绑定初始装备无需保护，不能放入黑匣。
- 战斗中只能在暂停的背包中改黑匣，不能介入已经开始的伤害结算。
- 已装备的普通组件需先卸到背包才能放入黑匣。仓库储物箱也显示黑匣内容，可直接存入箱子。

## 保险与物品状态

`resources/items/components.json` 新增 `circuit_breaker` 原型，图标为项目内绘制的 SVG。实际保险核心是具有唯一 instance_id 的 GLoot 物品，不再只用布尔值代表持有。

保险核心只有位于黑匣才启用 `CircuitBreakerComponent`。触发记录写入核心的 `circuit_breaker_used` 属性；取出、交换、装备变化、跨房间与读档均不刷新。换成普通组件后，黑匣只提供死亡保护，不再提供致命伤害保险。已触发的核心也可移出，黑匣仍能保护其它物品。

出击时，如果玩家随身持有保险核心，会默认放回黑匣（与原物品交换），并重置本轮出击的使用标记。放在仓库箱内的核心不会自动取出。拾取和仓库校验均禁止同时持有多枚核心。当前尚无 Boss 补发奖励接入点，不会在死亡回仓或加载新玩家时补发丢失的核心。

## 保存、死亡与放弃行动

背包快照新增 `blackbox` 槽。仓库 v1 存档保持兼容：缺少该字段时迁移旧保险状态；包含明确空黑匣的新存档不会获赠核心。保险状态以物品位置及实例属性为准。

从仓库出击的行动只在磁盘保存黑匣和绑定初始装备的恢复配置，不提前保存其余战利品。更改黑匣即时更新保护配置，写失败时还原本次存取；保险触发立即持久化已使用标记。成功撤离时完整保存装备、背包与黑匣。

死亡后关闭背包，保存恢复配置：黑匣中的一件物品与绑定初始装备保留，其余随身普通物品丢失，仓库箱内物品不受影响。死亡结算完成后可返回仓库；写盘失败时停留在可重试的死亡页，不允许 Esc 跳过未保存结算。保险核心若在普通背包中，会与其它未保护物品一起丢失。

实际行动中按 R 表示放弃本次行动并按相同保护规则回仓。原 `scenes/bootstrap/main.tscn` 调试入口仍保留 R 重开机制，调试入口的死亡不触发永久死亡结算。完整的楼层中途续玩不在本次范围内。
