# 启动界面与角色确认

F5 主入口为 `scenes/ui/start_menu.tscn`，使用现有像素字体和暗色终端配色。左侧操作，右侧原样显示用户提供的机甲图 `assets/art/ui/standard_chassis_portrait.png`；不改变战斗角色贴图。按 1280×720 排版，随窗口等比缩放居中，支持鼠标、Tab/Enter 和 Esc 返回。

- 继续当前存档：存在且可解析的 `WarehouseStore` 文件才能进入，读取已有装备和仓库，不重新生成角色。
- 开始新存档：进入角色确认页，当前仅开放“标准机体”，初始普通制式警棍一把；不会在打开角色页时修改存档。
- 已有存档：角色确认后显示重开确认页。取消不改文件；确认后原始文件复制到同目录 `<save_path>.backup-<unix时间>-<单调时间>`，再原子写入空白版本 1 profile。仓库随后初始化普通开局配装。
- 损坏存档：禁用继续，保留错误提示，允许通过明确的新建确认备份原始坏文件后重开。
- 备份或写入失败：保持原文件及原缓存，不进入仓库，显示失败原因。

继续/新建成功后清空上一局 RunManager 临时状态，再进入原 `warehouse_main.tscn`。直接仓库和战斗场景保留为调试入口，不改原有试验场/出击/撤离路径。

验证：`start_menu_check.gd` 24 项检查，无头及 macOS 图形模式通过；包含真实鼠标按钮、默认警棍、原装备实例继续读取、新建备份逐字节保留、取消、坏档恢复和保存失败。另执行 48 项单元测试和仓库 54 项回归。测试均使用独立 `start-menu-check.json` 并清理，不重置玩家真实存档。既有测试退出可能出现 ObjectDB/资源未释放警告。未验证 Windows 导出。
