# 固有突进与义体迁移实施说明

> 状态：v1.5 已实施；固有突进、四种义体、背包/掉落/敲合、存档迁移和专项测试已接入。

## 1. 固有突进

Space 触发所有玩家固有的突进。有 WASD 输入时沿输入方向突进，无输入时沿鼠标瞄准方向突进。基础步行最高速度保持 `125 px/s`；突进速度 `420 px/s`、持续 `0.20 s`、平地距离约 `84 px`、冷却 `1.2 s`。期间方向固定，撞墙提前结束且保留冷却。

突进前 `0.15 s` 提供无敌。撞墙、死亡、重置或疾行协议紧急撤离提前取消突进时，立即取消本次突进无敌，不影响受击保护、断路保险等其它无敌来源。突进不穿墙、不跨越未明确授权的障碍，武器与格挡仍按各自状态规则工作。

突进碰撞半径为 `14 px`。每名敌人每次突进最多命中一次，造成 2 点伤害和约 `0.65 s` 硬直，可打断攻击前摇；路径扫描不得隔墙命中。撞门沿用 `160 px` 噪声与门后击倒规则。

## 2. 单槽义体

义体槽最多装备一件单功能或复合义体。槽位为空时不提供效果；物品可以整体自由装卸，模块敲合后不可拆分。义体没有品质、词条或升阶，同类模块不叠加。不同义体与复合义体敲合时取模块集合并集，顺序无关。

- **智能火控**：仅修改可飞行、可转向的普通实体弹丸；生成时在准星扇区内锁定一次，目标失效后不换锁。
- **爆裂弹仓**：普通实体弹丸首次有效碰撞时产生一次范围伤害；已有爆炸、范围或链式攻击不重复附爆。
- **战术协处理器**：兼容枪械按住持续射击；过热停火，恢复到可射击阈值后继续；不新增弹匣或换弹键。
- **光学入侵器**：突进时让索敌单位脱锁并追查最后位置；不撤销既有攻击，玩家开火不破除。

同一行动内继续下一层时保留义体；撤离、死亡或重新开局时全部清除，不进入仓库或黑匣。投射物生成时快照追踪与爆炸模块，换装不追溯修改场上已有投射物。

## 3. 架构迁移

- 把突进参数从 `WheelMobilityMode` / 品质表迁入独立 `DashConfigData` 与 `DashController`；
- 新增 `CyberwareData`、义体物品模块集合与 `CyberwareController`；
- 玩家场景始终创建并启用 `DashController`，不再根据装备决定 Space 是否有效；
- 删除品质对突进伤害和冷却的影响，制式/改良/原型三档不再适用于突进；
- 旧 `MobilityController`、轮式/四足/飞行资源和数字键切换已退出玩家场景与正式运行时；历史脚本/资源仅供旧提交和未迁移测试对照，不再被正式入口引用；
- 旧存档中的机动装备不得转换为永久义体；加载时移除旧机动槽物品并给予一次明确迁移提示；
- 突进残影改由 `DashController` 的开始/结束事件驱动，与义体装卸无关。

## 4. 与疾行协议的关系

疾行协议仍可缩短冷却、把无敌延长至完整突进、保留动量、预测落点或增加储存次数。这些是协议效果，不属于义体品质或升阶。光学入侵器只增加脱锁，不改变突进距离、冷却或无敌参数。

## 5. 验收替换

`dash_check.gd` 与 `dash_invulnerability_check.gd` 已替换旧轮式专项，覆盖方向锁定、约 84 px 位移、伤害去重、攻击打断、冷却、无敌自然到期、撞墙、隔墙和低物理频率路径扫描。`cyberware_check.gd` 覆盖四模块敲合、追踪/爆炸快照、持续射击边界、普通敌人脱锁以及跨层/行动结算生命周期。旧机动品质测试只保留历史记录，不作为 v1.5 通过证据；疾行协议的冷却/次数天赋仍属于后续独立接入范围。
