# 盾兵屏障技能

`heavy_anchor.tres` 启用屏障技能。发现同房间、视野内的目标且冷却完成后，盾兵停步施放；捕获施放时的玩家方向，此次屏障不追踪转向。

- 播放现有八帧 `cast_barrier_down`（原生 AnimatedSprite2D）；暂时隐藏普通身体，避免叠出两个角色。
- 前 0.4 秒准备，展开第 5 帧时启用屏障判定；展开后持续 3 秒，动画结束停留最后一帧。
- 施放开始计 6 秒冷却。到期恢复正常动画和 AI；硬直中断、死亡进入自爆等待时立即清除屏障。
- 屏障宽 96、厚 8，位于施放方向前方 28 像素。单独使用第 9 物理层（256），不阻挡角色移动。
- 只有玩家阵营子弹查询此层；整段物理帧位移做射线检测，避免高速子弹跳过薄屏障。敌方子弹不被吸收，盾兵背后仍有受伤判定。
- 美术使用已确认的正面八帧。物理判定支持上下左右与任意施放方向；本次没有生成其他朝向的角色美术。

主要文件：`enemy_barrier_skill.gd` 负责施放及碰撞生命周期，`enemy_controller.gd` 触发及取消技能，`projectile.gd` 做玩家子弹拦截，`EnemyProfile` 提供开启、持续和冷却参数。
