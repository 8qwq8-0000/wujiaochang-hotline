# 普通战斗区域稀疏地面杂物

2026-10-23，用户希望地面不再空旷。四种正式房型在原有FloorBloodDecals之后添加FloorClutter，单一静态CanvasItem，z=-1，无碰撞、导航修改、处理循环或拾取行为。

每区新增3处小红血印，以及各10～14组碎石、金属碎零件和门板碎片，总计33～45组，受摆放安全条件限制可能减少。血印复用已确认喷血动画的16向落地纹理；金属片、螺栓使用既有炸弹碎片图集中的灰色部件；门板碎片裁取AutomaticDoor同款门叶贴图；碎石使用低色数原生像素多边形。未调用新增付费素材生成，也未替换原素材。

位置与尺寸、角度、透明度按run_seed、楼层、区域、房型独立确定，不使用全局随机数，不影响敌人或掉落抽取。同一局重开保持不变，不同局改变。避开完整掩体、窗、导航障碍、炮台、小箱子、门扇范围、补给/出口、通道、敌人初始位置和已有血迹。细碎零件压低亮度并压扁到地面，避免与可拾取装备混淆。

验证：`godot --headless --path . --script res://tests/integration/floor_clutter_check.gd`，495/495。覆盖四房型、同种子复现、不同种子改变、四类杂物、数量预算、避障和无物理节点。窗口模式追加`-- --capture`，实机全景位于`docs/art/validation/floor_clutter_v1/`，已目视复核。原有血迹检查单独回归；当前未进行Windows导出。
