# 第二结局楼顶单挑与入场剧情

日期：2026-11-04。本地已接入正式关卡，不代表已发布或完成连续战斗平衡验收。

## 正式流程

沿用第一层核心、Codex同行、第三层祭坛三波突袭的前置。携带真实核心、有存活Codex并完成突袭后进入楼顶，转入二结局，不生成原一结局的两批守卫，也不启动旧三节点接管。

入场使用现有底部通信面板，逐段暂停，按Enter或点击继续：

1. Codex说明在祭坛维持连接，把求救接回公共频道。
2. 神像回应：“请保持安静。未经许可的声音，会惊醒她。”
3. Codex说明中枢把求救当成噪声，接入核心后由玩家拦住神像。

对话结束才从背包转移核心、解除携带诅咒、恢复正常耐久；苏醒演出期间不允许玩家攻击或移动。神像从原雕像切换为已审阅的正面悬浮造型，离开底座后开始单挑。

Codex留在祭坛旁，免伤，不射击、不成为防守目标。玩家与神像直接交战；神像全程可受伤，无护盾阶段。初始耐久60，攻击间隙以每秒60像素在中上半场二维游走，中心范围为X 330～950、Y 330～560，尽量与玩家保持160像素距离；施法时停住。使用已制作的小幅正面移动与施法动画。

当前战斗在神像苏醒后同时生成左右翼卫，耐久分别为10／8；翼卫不作为击败神像的前置目标。神像出招期间翼卫仍自主移动与攻击，神像倒下时一并清场。

## 三种技能

- 回声落点：三次记录玩家位置，落点放置后不再追踪。每处有0.8秒预警，释放时命中一次。地面椭圆半径为40×22，与显式预警边界一致。
- 光环裁断：三条平行纵向光带，宽20、中心间隔78，覆盖可战斗区域；0.96秒预警后光带滞留0.6秒，期间进入光带也会受伤，同一次攻击最多受伤一次。光带间空隙安全。地面条带与实际伤害范围一致。
- 护子震波：抱紧幼鲸的前摇0.7秒后释放，环半径在0.66秒内从24扩大至240，地面纵向比例0.55。环边采用连续扫掠判定以避免跳帧穿漏；同一波对玩家最多接触一次，中心不持续伤害，突进无敌有效。

攻击基础伤害均为1、不可普通格挡，沿用玩家通用无敌和防御处理。三招前半血依次释放，正常恢复间隔1.25秒；半血后回声与光环的间隔缩短到0.25秒，其余恢复0.85秒，复用已有技能，不增加新机制。

技能逻辑和预警使用随暂停冻结的物理时钟。玩家死亡或Boss倒下，立即停止调度并清除未释放攻击与场上特效。

## 胜利与恢复

Boss倒下后暂停战斗，播放“封锁解除—求救接通—接线员回应”的结局通信。通信完成后才置位`channel_takeover_complete`、清除必杀目标并开放出口，沿用原通关保存UI写入`ending=channel_returned`。不宣称所有人员已获救。

开场及结局通信期间均不能提前通关；保存按钮沿用原子提交和重复结算保护。死亡、主动放弃仍走现有行动失败流程。

楼顶安全检查点保留在核心接入之前。退出后继续会恢复原核心、生命及前置，重播入场剧情并重新打完整场Boss，不保存半场血量，也不凭退出恢复治疗。通关保存成功才清除检查点。

未满足二结局条件时仍走原一结局：三名开场守卫、苏醒、五名联动守卫和最后一次直伤。
