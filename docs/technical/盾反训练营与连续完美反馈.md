# 盾反训练营与连续完美反馈

## 玩家入口与操作

仓库上方中间的「盾反训练营」通道（270,100），靠近按 E 进入。玩家位于环心，三只静止的远程机器人环形排列，默认各 3 点血，按照 01→02→03→01 顺序每隔 0.9 秒发射一颗子弹。死亡的机器人自动跳过；全部击败后按 R 重新练习。

右键朝向来弹进行盾反，WASD 移动。左侧参数滑块立即生效：

| 参数 | 默认值 | 调整范围 |
| --- | --- | --- |
| 射击间隔 | 0.9 秒 | 0.4–2.0 秒，步长 0.1 |
| 子弹速度 | 260 px/s | 120–600 px/s，步长 20 |
| 机器人血量 | 3 点 | 1–10 点，步长 1 |

修改参数清理旧子弹并重新计时；修改血量会重建全部机器人。鼠标位于参数面板上或拖动滑块时暂停新发射，防止操作参数时继续刷出攻击。R 或「重置训练」重新加载训练营，恢复玩家、机器人和统计，保留当前三项参数。「返回仓库」通过现有场景切换回到仓库。

训练使用独立临时战斗，进入前保存仓库配装；训练中的击杀、受伤、死亡和重置不结算到正式存档。训练参数只在这次训练及其 R 重置中保留。

## PERFECT! 反馈

采用已确认的紫色街机像素字图片，原始生成稿和提示词位于 `art_sources/ai_drafts/ui/perfect_parry_v1/`，运行素材位于 `assets/art/ui/feedback/`。

所有通过 VFXManager 运行的战斗均可触发：第一次完美盾反后 1.2 秒内再次完美盾反，玩家头顶显示一次 PERFECT!，缩放弹出并上浮淡出，持续 0.7 秒。连续成功第二次起，每次完美盾反都会重新播放提示；第三、第四次也会显示。普通格挡、受伤、超时或切换场景会打断计数；暂停冻结计时。训练调参也清空半截连击与提示。既有盾反伤害、反射和金色闪光保持原有结算。
