# 普通战斗地图扩展

正式地图池包含错位公寓、装卸车间、货运中庭、双轨货运站四种地图。每层仍抽取两个不同区域；每个区域六名必杀敌人，清场打开下一通道，进入下一区后封闭回程，最终区域提供撤离出口。

## 货运中庭

资源标识：`freight_atrium`。

保留多房间版本：左侧安检缓冲区、上方控制室与设备室、中央设备区、下方两个装卸区，十二扇自动门连接。中央四组设备分散摆放，留出横穿近路及中间的纵向通道。地面有运输标线、分区文字及装卸框线。

六名敌人沿用原有配置：三名近战、两名远程、一名盾兵。触电器仅在中央战斗区与东侧过道随机出现，排除入口和封闭侧室。中央路线及下方装卸区步道不生成随机实体障碍。

## 双轨货运站

资源标识：`dual_track_depot`。

采用完整开放站厅，两条纵向货运设备带由十八件现有货箱、机器、控制台组合而成。设备带是可步入的地面装卸区域，各件设备有独立碰撞，不生成整块不可进入的大岛。三处横向换线口编号 01/02/03，两侧各有一条纵向长射击线。

两个远程哨兵分别位于西侧北端、东侧南端，三名近战分布在货箱侧翼，一名盾兵守中央换线口。专用 `freight_lane_marksman.tres` 将射程设为 420 px、攻击间隔 1.8 s、前摇 0.55 s，并沿纵向巡逻；其他地图的远程配置保持原值。

触电器避开入口、横向换线口和两侧长线，随机生成于其余指定区域。随机小障碍同样避开通行路线。三个炸弹箱沿用敌人附近的随机生成与爆炸规则。

## 素材与生成

两张新地图复用已有地板、分方向墙角、货箱、机器、控制台、敌人和环境道具素材；装卸底纹、箭头、编号由原生绘图绘制。没有新生成的美术图片依赖。

`CombatLayoutData.clear_lanes` 随房间缩放，限制随机小障碍与触电器的摆放；它本身不参与物理碰撞、视线或导航烘焙。有保护路线的地图采用更细的障碍采样，并允许在边缘安全地带生成小型道具。

专项检查覆盖多随机种子的通行路线与目标可达性、玩家真实穿门及横穿、长线碰撞查询、328 px 实际射击，以及随机道具对通路的避让。通用检查覆盖四种地图的随机选择、首区/末区位置及区域连接。测试与截图使用隔离存档。
