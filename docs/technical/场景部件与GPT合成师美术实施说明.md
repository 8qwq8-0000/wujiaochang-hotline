# 场景部件与 GPT 合成师美术

当前工程已接入新的充电/配电箱、炸药箱、普通门开关两态、下层电梯入口及 GPT 合成师。素材位于 `assets/art/environment/refined/`，由 `scripts/presentation/refined_environment_art.gd` 管理表现，不改变原玩法和碰撞规则。

PowerBox、FuelBarrel、AutomaticDoor 的原生场景增加 RefinedArt 子节点；ExitElevator 在 ready 时添加同一表现节点，因此继承/动态创建的出口也获得新美术。原有互动与状态仍由原脚本管理。普通滑门开关切图，铰链门沿原角度旋转，未覆盖同学正在修改的自动门逻辑。电梯禁用时变暗，启用后亮起向下标识。配电箱领取及破坏后区分状态，炸药引爆后由现有火区表现接管。

仓库中的 SynthesisNPC 保留位置和交互区域，仅将占位外观替换为用户指定的 GPT 白发紫角龙形人物；名称改为“合成师 · GPT”，工坊标题改为“GPT 的合成工坊”。角色不是网上搜索结果的 Logo 头拟人图。

独立地图美术副本已同步新素材并展示各部件。地图背景仍是独立副本，本次部件与 NPC 的替换则已进入当前工程。

当前验证：合成师交互与升级 40/40，通过图形模式确认龙娘外观和 GPT 名称。共享素材检查 18/19，其中铰链门角度跟随断言失败；本次恢复未修改门适配器。测试退出仍有既有资源释放警告。未进行 .NET 或 Windows 导出验证。
