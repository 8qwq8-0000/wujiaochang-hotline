# 五角场热线 macOS 通用预览版 v0.2.0-macos-preview.2

基于合入 `v0.2.0` Windows / Android 正式版改动后的最新主分支导出，支持 Intel 与 Apple 芯片。

下载 ZIP 后解压，运行 `五角场热线.app`。应用采用 Godot 内置临时签名，未使用 Apple Developer ID 签名或 Apple 公证。首次启动如被 macOS 拦截，请在“系统设置 → 隐私与安全性”中确认来源并允许打开。

本版包含主菜单机甲头部图标、地下整备大厅门位置修正、义体初始开火资源识别修正等已合入主分支的改动。安卓版自动射击只作用于移动端。

已在 Windows 上完成 Godot 导出及 ZIP、架构、版本和资源内容检查。尚未在 Mac 实机启动；尤其是 Intel Mac 的运行情况需要玩家验证。
