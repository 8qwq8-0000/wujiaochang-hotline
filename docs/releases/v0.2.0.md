# 五角场热线 v0.2.0

## 下载

- Windows：下载 ZIP，解压后运行 `五角场热线.exe`，并保留同目录下的 `.pck` 文件。
- Android：下载 APK 安装。此版启用新的正式签名，无法覆盖安装此前的调试签名试玩版；请先备份需要保留的内容，再卸载旧版。

## 本次更新

- 安卓版增加默认开启的自动射击：屏幕内、同房间且无遮挡的敌人会成为射击目标；拖动射击摇杆时由玩家手动控制，松开后恢复自动射击。蓄力武器仍需手动操作。
- 安卓触控义体背包和义体序列恢复到桌面版的交互与布局；新档获得初始开火义体。
- 地下整备大厅的门随墙体布局定位，修正分辨率变化后的悬空问题。
- 使用主菜单机甲头部制作桌面与安卓图标。
- 正式包不含测试工具界面及调试场景。

## 验证说明

已运行 Godot 单元测试及触控、设置、整备大厅和初始开火义体集成检查，并核对 APK 的版本、签名和正式包内容。安卓实体设备的手感与兼容性仍需安装后验证。
